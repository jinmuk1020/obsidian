# 데이터 거버넌스

## 핵심 정의
데이터 거버넌스는 조직이 데이터를 신뢰할 수 있는 자산으로 관리하기 위해 소유권, 품질, 보안, 접근 권한, 표준, 책임 체계를 정하는 활동이다. 데이터 분석 이전에 데이터가 어떤 규칙으로 생성되고 관리되는지를 다룬다.

## 작동 방식
거버넌스는 데이터 정의 표준, 메타데이터 관리, 품질 관리, 개인정보와 보안 정책, 데이터 소유자 지정, 접근 권한 관리로 구성된다. 좋은 거버넌스는 데이터 사용을 막는 통제가 아니라 안전하고 일관된 활용을 가능하게 하는 기반이다.

## 실무적 의미
분석 프로젝트에서는 같은 지표가 부서마다 다르게 계산되는 문제를 줄이고, 데이터 출처와 품질을 추적하게 해준다. 머신러닝에서는 학습 데이터의 책임성과 재현성을 높인다.

## 주의할 점
거버넌스를 문서와 승인 절차만으로 운영하면 현업이 우회하게 된다. 실제 데이터 흐름과 업무 속도에 맞는 최소한의 표준과 자동화가 필요하다.
