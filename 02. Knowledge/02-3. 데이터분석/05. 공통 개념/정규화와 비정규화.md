# 정규화와 비정규화

## 핵심 정의
정규화와 비정규화는 데이터 구조를 중복 없이 일관되게 만들 것인지, 조회 성능과 사용 편의를 위해 의도적으로 중복을 허용할 것인지에 관한 설계 선택이다.

정규화는 데이터를 여러 테이블로 나누어 중복과 갱신 이상을 줄인다. 비정규화는 자주 함께 조회하는 데이터를 한곳에 모으거나 요약값을 저장해 읽기 성능을 높인다.

## 작동 방식
운영 데이터베이스에서는 무결성과 유지보수가 중요하므로 정규화가 기본이다. 반면 데이터 마트, 리포트, 대규모 조회 시스템에서는 분석 속도와 단순성을 위해 비정규화를 선택할 수 있다.

## 실무적 의미
분석 환경에서는 원천 데이터의 정규화 구조를 그대로 쓰면 조인이 많아지고 쿼리가 복잡해질 수 있다. 반대로 비정규화를 과도하게 하면 데이터 불일치와 갱신 비용이 커진다. 어떤 질의가 자주 일어나는지, 데이터가 얼마나 자주 바뀌는지에 따라 선택해야 한다.

## 주의점
정규화와 비정규화는 선악의 문제가 아니다. 저장 무결성, 조회 속도, 갱신 비용, 분석 편의성 사이의 트레이드오프다.
