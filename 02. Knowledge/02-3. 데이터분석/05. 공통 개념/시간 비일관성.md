# 시간 비일관성

## 핵심 정의
시간 비일관성은 사람이 미래에는 어떤 선택을 하겠다고 계획해놓고, 시간이 가까워지면 현재의 유혹이나 비용 때문에 다른 선택을 하는 현상이다. 선호가 시간에 따라 안정적으로 유지되지 않는 문제다.

## 작동 방식
장기적으로는 저축, 운동, 학습, 절제를 원하지만, 단기적으로는 즉각적인 보상과 편안함을 더 크게 느낀다. 현재 편향과 쌍곡 할인은 시간 비일관성을 설명하는 대표 개념이다.

## 실무적 의미
기획에서는 리텐션, 습관 형성, 구독, 목표 달성 서비스, 학습 앱, 건강 행동 설계에서 중요하다. 사용자가 미래 목표를 지키도록 돕기 위해 알림, 약속 장치, 작은 단계, 즉각 피드백을 설계할 수 있다.

## 주의할 점
시간 비일관성을 이용해 사용자를 중독적으로 붙잡는 설계는 위험하다. 사용자의 장기 이익을 돕는 개입과 단기 충동을 악용하는 개입을 구분해야 한다.

- Predictably Irrational 소스 분석
