# 과적합 방지

## 핵심 정의
과적합 방지는 모델이 훈련 데이터의 우연한 패턴과 잡음까지 외워서 새로운 데이터에서 성능이 떨어지는 문제를 줄이는 방법들의 묶음이다. 목표는 훈련 성능을 무조건 높이는 것이 아니라, 보지 못한 데이터에도 잘 일반화되는 모델을 만드는 것이다.

## 작동 방식
대표적인 방법은 훈련 데이터와 검증 데이터를 분리하는 것이다. 모델이 학습에 쓰지 않은 데이터에서도 성능을 유지하는지 확인해야 실제 문제에 적용할 수 있다.

정규화, 교차검증, 조기 종료, 모델 단순화, 데이터 증강, 드롭아웃, 앙상블은 모두 과적합을 줄이기 위한 도구다. 각각은 모델의 복잡도를 제한하거나, 검증 절차를 강화하거나, 데이터의 다양성을 늘리는 방식으로 작동한다.

## 실무적 의미
머신러닝 실무에서 과적합 방지는 모델 선택의 핵심 기준이다. 훈련 점수보다 검증 점수, 테스트 점수, 오류 분석을 함께 봐야 한다. 특히 데이터가 적거나 특징 수가 많거나 모델이 복잡할수록 과적합 위험이 커진다.

## 주의점
과적합을 피하려고 모델을 지나치게 단순하게 만들면 과소적합이 된다. 중요한 것은 복잡도를 무조건 낮추는 것이 아니라, 문제의 신호를 충분히 학습하면서 잡음에는 덜 민감하게 만드는 균형이다.
