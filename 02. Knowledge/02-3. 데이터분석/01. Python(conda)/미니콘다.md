# 미니콘다

## 핵심 정의
미니콘다는 conda 패키지 관리자와 최소한의 파이썬 실행 환경만 포함한 가벼운 배포판이다. 많은 과학 계산 패키지를 미리 포함하는 아나콘다보다 작고, 사용자가 필요한 패키지를 직접 선택해 설치할 수 있다.

데이터 분석 환경을 깔끔하게 유지하려면 처음부터 필요한 것만 설치하는 편이 유리하다. 미니콘다는 이런 방식에 잘 맞는 출발점이며, 프로젝트별 가상환경을 만들고 관리하는 데 자주 사용된다.

## 작동 방식
미니콘다를 설치하면 `conda` 명령을 통해 환경을 만들고 활성화하며 패키지를 설치할 수 있다. 각 환경은 독립적인 파이썬 버전과 라이브러리 집합을 가진다. 프로젝트별로 환경을 나누면 패키지 충돌을 줄이고 재현성을 높일 수 있다.

conda는 파이썬 패키지뿐 아니라 일부 네이티브 라이브러리 의존성도 함께 관리한다. 그래서 NumPy, Pandas, scikit-learn처럼 컴파일된 구성 요소를 포함하는 패키지를 다룰 때 편리하다.

## 실무적 의미
미니콘다는 분석가가 로컬 장비, 실습 환경, 서버 환경을 비슷하게 맞추는 데 도움을 준다. 특히 여러 머신러닝 프로젝트를 병행할 때 프로젝트마다 다른 파이썬 버전과 라이브러리 버전을 분리할 수 있다.

새 프로젝트를 시작할 때는 기본 환경에 패키지를 계속 추가하기보다 새 환경을 만들고 필요한 패키지만 설치하는 것이 좋다. 이렇게 해야 나중에 환경 파일을 통해 같은 조건을 다시 만들 수 있다.

## 주의할 점
미니콘다는 패키지 충돌을 줄여 주지만 완전히 없애 주지는 않는다. conda와 pip를 섞어 쓸 때는 설치 순서와 채널을 조심해야 하며, 문제가 생기면 환경을 새로 만드는 것이 더 빠를 때도 있다.

또한 base 환경을 실험용으로 쓰기 시작하면 시간이 지날수록 관리가 어려워진다. base는 conda 자체를 관리하는 최소 환경으로 두고, 실제 작업은 별도 환경에서 진행하는 편이 안전하다.
