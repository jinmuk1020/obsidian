# 휴리스틱

## 핵심 정의

> 휴리스틱은 복잡한 문제를 빠르게 판단하기 위해 사용하는 경험적 규칙이나 인지적 지름길이다.

* **본질:** 모든 정보를 계산할 수 없는 상황에서 제한된 단서로 빠른 결론을 만든다.
* **맥락:** 의사결정, 사용자 행동, 데이터 해석, UX, 정책 설계, 게임 디자인에서 중요하다.

## 작동 방식

사람은 시간과 주의가 제한되어 있기 때문에 모든 판단을 분석적으로 처리하지 않는다. 대신 쉽게 떠오르는 사례, 처음 제시된 기준, 대표적으로 보이는 특징, 감정적 단서를 사용해 빠르게 판단한다.

* **메커니즘:** 복잡한 질문을 더 쉬운 질문으로 대체해 판단한다.
* **구체적 예시:** 실제 통계보다 최근에 본 사례를 근거로 위험을 판단한다.
* **연계 프로세스:** 정보 부족 또는 시간 압박 -> 단서 선택 -> 빠른 판단 -> 행동.

## 실무적 의미

휴리스틱은 오류만 만드는 것이 아니라 실제 환경에서 효율적인 판단을 가능하게 한다. 문제는 어떤 상황에서 유용하고, 어떤 상황에서 편향으로 변하는지 구분하는 것이다.

* **안정성:** 중요한 의사결정에서는 휴리스틱 판단을 검증할 절차를 둔다.
* **측정 가능성:** 판단 결과가 실제 데이터와 얼마나 어긋나는지 확인한다.
* **데이터 기준:** 표본 크기, 대표성, 최근성, 기준점 영향을 함께 본다.

## 주의할 점

휴리스틱을 모두 제거할 수는 없다. 설계자는 사용자가 휴리스틱을 쓴다는 사실을 전제로, 더 나은 판단을 쉽게 만드는 환경을 제공해야 한다.

* **관점의 한계:** 빠른 판단은 때로 정확하고 때로 체계적으로 틀린다.
* **상관관계 vs 인과관계:** 눈에 띄는 패턴을 원인으로 단정하지 않는다.
