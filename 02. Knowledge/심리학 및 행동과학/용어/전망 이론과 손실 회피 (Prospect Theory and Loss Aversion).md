# 전망 이론과 손실 회피 (Prospect Theory and Loss Aversion)

## 핵심 정의

> 전망 이론은 사람이 절대적 부의 수준보다 기준점 대비 이득과 손실을 중심으로 가치를 평가한다는 이론이며, 손실 회피는 같은 크기의 이득보다 손실을 더 크게 느끼는 경향이다.

* **본질:** 사람은 이득보다 손실에 더 민감하고, 기준점이 판단의 출발점이 된다.
* **맥락:** 가격, 보상, 위험 선택, 투자, 게임 경제, UX 손실 경험에서 중요하다.

## 작동 방식

사람은 현재 상태나 기대 상태를 기준점으로 삼고, 그보다 좋아지면 이득, 나빠지면 손실로 해석한다. 같은 금액이라도 얻는 기쁨보다 잃는 고통이 더 크기 때문에 손실 가능성은 선택을 강하게 바꾼다.

* **메커니즘:** 기준점 설정 -> 이득/손실 분류 -> 손실에 더 큰 심리적 가중치 부여.
* **구체적 예시:** 1만원을 얻는 기쁨보다 1만원을 잃는 고통이 더 크게 느껴진다.
* **연계 프로세스:** 기준점 형성 -> 위험 평가 -> 선택 회피 또는 위험 감수.

## 실무적 의미

사용자는 기능을 새로 얻는 것보다 이미 있던 기능을 잃는 것에 더 크게 반응할 수 있다. 가격 인상, 혜택 축소, 아이템 너프, 데이터 손실, 진행도 초기화는 모두 손실로 해석된다.

* **안정성:** 손실로 느껴질 변화를 예고하고 보상 맥락을 함께 설계한다.
* **측정 가능성:** 변화 전후 불만, 이탈, 재구매, 사용량을 본다.
* **데이터 기준:** 사용자의 기준점이 무엇인지 세그먼트별로 확인한다.

## 주의할 점

손실 회피를 이용하면 강한 행동 유도는 가능하지만, 과도하게 사용하면 불안과 반감을 만든다. 특히 희소성, 한정 시간, 손실 경고를 남발하면 신뢰가 약해진다.

* **관점의 한계:** 모든 사용자가 같은 기준점을 갖고 있지는 않다.
* **상관관계 vs 인과관계:** 이탈이 가격 때문인지 손실로 느낀 변화 때문인지 구분해야 한다.
