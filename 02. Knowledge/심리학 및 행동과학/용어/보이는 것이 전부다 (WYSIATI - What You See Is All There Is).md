# 보이는 것이 전부다 (WYSIATI - What You See Is All There Is)

## 핵심 정의

> WYSIATI는 현재 눈앞에 있는 정보만으로 그럴듯한 이야기를 만들고, 보이지 않는 정보의 부재를 충분히 고려하지 않는 경향이다.

* **본질:** 사람은 정보의 양보다 눈앞 정보의 일관성에 더 쉽게 설득된다.
* **맥락:** 의사결정, 사용자 조사, 데이터 해석, 여론 판단, 기획 검토에서 중요하다.

## 작동 방식

사람은 현재 접근 가능한 정보로 빠르게 이야기를 구성한다. 정보가 부족해도 그 부족함 자체를 문제로 느끼기보다, 주어진 정보끼리 잘 맞으면 높은 확신을 갖는다.

* **메커니즘:** 제한된 정보 -> 일관된 이야기 구성 -> 과도한 확신.
* **구체적 예시:** 소수의 강한 사용자 피드백만 보고 전체 사용자 요구라고 판단한다.
* **연계 프로세스:** 정보 노출 -> 즉각적 해석 -> 누락 정보 무시 -> 빠른 결론.

## 실무적 의미

프로젝트 의사결정에서는 "지금 보이는 증거"와 "아직 확인하지 않은 증거"를 분리해야 한다. 특히 사용자 인터뷰, 커뮤니티 반응, 초기 지표는 강하게 보이지만 전체를 대표하지 않을 수 있다.

* **안정성:** 결론 전에 누락된 데이터와 반례를 명시한다.
* **측정 가능성:** 표본 크기, 출처, 편향 가능성을 함께 기록한다.
* **데이터 기준:** 현재 데이터가 어느 집단을 대표하는지 확인한다.

## 주의할 점

WYSIATI는 빠른 판단을 돕지만, 불완전한 정보로 너무 자신 있게 결정하게 만든다. 정보가 적을수록 더 조심해야 하는데, 오히려 이야기가 단순해서 더 확신하기 쉽다.

* **관점의 한계:** 일관된 이야기가 사실이라는 보장은 없다.
* **상관관계 vs 인과관계:** 눈앞의 패턴이 실제 원인을 설명한다고 단정하지 않는다.
