# 시스템 (System)의 정의

## 핵심 설명

시스템은 특정한 목적을 성취하기 위하여 여러 구성인자가 서로 유기적으로 연결되어 상호작용하는 요소들의 집합입니다 [1]. 하나 이상의 요소를 가지고 있어야 하며, 모든 요소가 독립적이지 않고 유기적인 상호작용 관계를 맺어야만 시스템으로 성립됩니다 [1]. 또한 외부로부터 얻은 투입물을 변환시켜 산출물을 내보내며, 개별 요소가 아닌 하나의 전체로서 인식되는 특성이 있습니다 [2].

## 핵심 포인트

- 유기적으로 연결된 요소들의 집합 [1]
- 특정한 공통 목적을 달성하기 위한 상호작용 [1, 2]
- 투입-변환-산출의 순환 과정 수행 [2]

## 중요성

조직의 문제를 단순한 단편적 현상이 아닌 유기적인 전체 구조 속에서 파악하여 근본적인 해결책을 찾게 해줍니다 [1, 2].

### 구체적 메커니즘

시스템은 외부 환경으로부터 자극이나 자원을 받아들이는 투입(Input) 과정을 거쳐 이를 유용한 형태로 처리(Throughput)하고 그 결과를 산출물(Output)로 내보내는 변환 메커니즘으로 작동합니다. 이는 단순히 개별 요소들이 나열된 것이 아니라, 특정한 목적을 성취하기 위해 여러 구성인자가 서로 유기적으로 연결되어 상호작용하는 요소들의 집합체입니다. 각 구성 요소는 독립적으로 움직이지 않고 시스템의 공통된 목표를 달성하기 위해 긴밀하게 협력하며, 이 과정에서 개별 요소의 단순 합보다 큰 상승효과를 창출합니다. 또한 시스템은 자체적인 통제 기능을 통해 안정성을 유지하며, 주변 환경을 의미하는 상위시스템과 내부 부품을 의미하는 하위시스템 간의 계층적 구조 속에서 기능을 수행합니다. 결과적으로 이러한 시스템적 접근은 복잡한 현상을 단편적인 부분이 아닌 하나의 전체(Whole)로서 인식하게 하여 문제 해결의 실마리를 제공합니다.

### 데이터와 구조

- 시스템의 3대 필수 조건: 하나 이상의 요소 집합, 상호작용하는 연결 관계, 공통 또는 특정한 목적 달성
- 기본적 활동영역 3단계: 외부 자원을 받아들이는 투입(Input), 자원을 처리하는 활동(Throughput), 산출물이나 부산물을 내보내는 활동(Output)
- 시스템 사고의 계층구조: 상위시스템(Top system), 시스템(System), 하위시스템(Sub system)
- 시스템의 5가지 주요 특징: 환경 투입물의 변환, 전체로서의 인식, 계층적 특성, 상승효과(Synergy), 통제(Control)
- 상위시스템의 구성 범위: 사람, 장소, 환경, 기후, 제도, 법규 등 시스템 기능에 영향을 미칠 수 있는 모든 외부 요인

### 사례와 적용

- 자동차의 계층적 시스템: 상위시스템(도로, 날씨, 교통법규), 시스템(자동차 자체), 하위시스템(엔진, 타이어, 브레이크, 핸들 등)
- 컴퓨터의 활동 영역 사례: 키보드나 스캐너를 통한 입력, 메모리와 프로세서를 통한 처리, 모니터나 프린터를 통한 산출
- 인체의 생체 시스템 사례: 입과 눈, 귀를 통한 자극 수용(투입), 뇌와 위의 활동(처리), 움직임이나 배설(산출)
