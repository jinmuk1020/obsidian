# 훈련 세트와 테스트 세트 (Training Set and Test Set)

## 출처

- Source ID: `16c9c71e-8140-4081-8963-cfe23b4dd1ed`
- Notebook: 내 정수

## 핵심 설명

머신러닝 모델의 성능을 공정하게 평가하기 위해 전체 데이터를 학습용과 평가용으로 나눈 것입니다 [11, 12]. 훈련 세트는 모델을 학습시키는 데 사용되며, 테스트 세트는 학습에 참여하지 않은 데이터를 통해 모델의 일반화 능력을 확인하는 데 쓰입니다 [9, 13]. 데이터를 나눌 때 특정 종류가 한쪽에 치우치면 샘플링 편향이 발생하여 모델이 올바르게 학습되지 않을 수 있습니다 [14, 15].

## 핵심 포인트

- 학습용(훈련 세트)과 평가용(테스트 세트) 데이터의 분리 [11]
- 훈련에 사용하지 않은 데이터로 모델 성능을 객관적으로 평가 [12]
- 전체 데이터를 대표할 수 있도록 골고루 섞어 나누는 것이 중요함 [15]

## 중요성

모델이 단순히 데이터를 외운 것인지, 아니면 실질적인 규칙을 학습한 것인지 검증하여 실전 투입 가능성을 판단하게 합니다 [11, 16].
