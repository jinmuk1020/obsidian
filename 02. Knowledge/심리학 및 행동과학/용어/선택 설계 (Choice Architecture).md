# 선택 설계 (Choice Architecture)

## 핵심 정의

> 선택 설계는 사람들이 결정을 내리는 환경, 정보 배열, 기본값, 절차를 의도적으로 구성하는 일이다.

* **본질:** 선택은 중립적인 진공 상태에서 이루어지지 않고, 제시 방식과 맥락의 영향을 받는다.
* **맥락:** UX, 정책, 가격표, 메뉴, 가입 절차, 게임 보상, 서비스 온보딩에서 중요하다.

## 작동 방식

선택 설계자는 무엇을 먼저 보여줄지, 어떤 옵션을 기본값으로 둘지, 선택지를 몇 개로 나눌지, 어떤 정보를 강조할지 결정한다. 이런 작은 구조가 사용자의 주의, 이해, 행동 비용을 바꾼다.

* **메커니즘:** 선택 맥락 구성 -> 주의와 해석 변화 -> 행동 분포 변화.
* **구체적 예시:** 복잡한 설정을 기본 추천값으로 제공하면 사용자의 결정 부담이 줄어든다.
* **연계 프로세스:** 목표 행동 정의 -> 선택 장벽 분석 -> 선택 환경 설계 -> 행동 결과 측정.

## 실무적 의미

선택 설계는 사용자를 설득하는 문구보다 더 강하게 작동할 수 있다. 좋은 선택 설계는 사용자의 목표를 더 쉽게 달성하게 하며, 나쁜 선택 설계는 실수와 후회를 만든다.

* **안정성:** 사용자의 이해와 철회 가능성을 보장해야 한다.
* **측정 가능성:** 선택률뿐 아니라 만족도, 취소율, 불만, 장기 유지율을 함께 본다.
* **데이터 기준:** 옵션 배치, 기본값, 설명 방식의 변화가 행동에 미치는 영향을 비교한다.

## 주의할 점

선택 설계는 항상 가치 판단을 포함한다. 어떤 선택을 더 쉽게 만들지 결정하는 순간 설계자는 사용자의 행동 방향에 개입한다.

* **관점의 한계:** 좋은 의도만으로 좋은 선택 설계가 되지는 않는다.
* **상관관계 vs 인과관계:** 선택률 상승이 사용자에게 더 좋은 결과를 의미하는지 따로 검증해야 한다.
