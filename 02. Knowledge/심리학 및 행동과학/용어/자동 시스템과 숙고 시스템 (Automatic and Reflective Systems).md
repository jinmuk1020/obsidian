# 자동 시스템과 숙고 시스템 (Automatic and Reflective Systems)

## 핵심 정의
자동 시스템과 숙고 시스템은 인간 판단을 빠르고 직관적인 사고와 느리고 의식적인 사고의 상호작용으로 설명하는 틀이다. 자동 시스템은 즉각적 인상, 습관, 감정 반응, 연상을 빠르게 만들어낸다. 숙고 시스템은 주의력과 노력을 들여 계산하고 비교하고 규칙을 적용한다.

이 구분은 사람이 항상 합리적으로 판단하지 않는 이유를 설명한다. 많은 판단은 숙고 시스템이 처음부터 계산해서 내리는 것이 아니라, 자동 시스템이 제안한 인상을 숙고 시스템이 검토하거나 그대로 승인하는 방식으로 이루어진다.

## 작동 방식
자동 시스템은 빠르고 에너지 소모가 적다. 얼굴 표정 읽기, 익숙한 길 찾기, 위험 신호 감지, 손실에 대한 즉각적 반응처럼 빠른 판단이 필요한 상황에서 유용하다. 하지만 직관은 맥락과 단서에 쉽게 끌리기 때문에 편향과 오판을 만들 수 있다.

숙고 시스템은 느리고 제한된 자원을 쓴다. 계산, 논리적 검토, 장기적 결과 비교, 규칙 적용이 필요할 때 작동한다. 그러나 숙고 시스템은 항상 깨어 있지 않다. 피로하거나 시간이 부족하거나 문제가 쉬워 보이면 자동 시스템의 판단을 충분히 검토하지 않고 받아들일 수 있다.

## 설계상 의미
기획과 디자인에서는 사용자가 모든 정보를 꼼꼼히 읽고 판단한다고 가정하면 안 된다. 기본값, 순서, 시각적 강조, 마찰, 표현 방식은 자동 시스템에 먼저 영향을 준다. 그래서 선택 설계는 사용자의 직관이 더 나은 방향으로 작동하도록 환경을 조정해야 한다.

게임 UX에서도 이 구분은 중요하다. 플레이어는 전투 중에 설명문을 분석하지 않고 색, 소리, 움직임, 피드백을 통해 즉각 판단한다. 반대로 빌드 구성, 전략 선택, 경제 관리처럼 장기 판단이 필요한 영역에서는 숙고 시스템이 작동할 시간을 줘야 한다.

## 주의할 점
자동 시스템은 나쁜 사고, 숙고 시스템은 좋은 사고라는 식으로 나누면 안 된다. 자동 시스템은 대부분의 일상 판단을 빠르게 처리하는 필수 기능이다. 문제는 직관이 잘못된 단서에 반응하거나, 숙고가 필요한 상황에서 검토가 생략될 때 생긴다.

또한 사용자의 자동 반응을 이용해 원치 않는 행동을 유도하는 설계는 장기 신뢰를 훼손한다. 좋은 넛지는 선택을 빼앗는 것이 아니라 사용자가 스스로 원할 가능성이 높은 행동을 더 쉽게 선택하게 돕는다.
