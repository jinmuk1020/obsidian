# 전역 인터프리터 락 (GIL)

## 출처

- Source ID: `3f215fbd-ca74-4d92-9e97-6f794cce83c1`
- Notebook: 내 정수

## 핵심 설명

CPython의 GIL은 한 번에 하나의 파이썬 명령만 실행되도록 강제하는 메커니즘으로, 멀티코어 환경에서도 파이썬 스레드가 진정으로 병렬 실행되는 것을 방해합니다. 이로 인해 CPU 위주의 작업에서 멀티스레드를 사용하면 오히려 문맥 전환 비용 때문에 성능이 떨어지는 현상이 발생할 수 있습니다. GIL 문제를 해결하기 위해 multiprocessing 모듈을 사용하거나 Cython을 통해 락을 해제하는 등의 병렬 처리 기법이 필요합니다. [4-7]

## 핵심 포인트

- CPython에서 한 번에 하나의 파이썬 명령어만 실행하도록 제한
- 멀티코어 시스템 활용을 방해하는 주요 성능 병목 원인
- 멀티프로세싱이나 저수준 확장을 통해 우회 가능한 제약

## 중요성

파이썬에서 하드웨어의 멀티코어 성능을 온전히 활용하기 위해 반드시 이해하고 극복해야 할 구조적 장벽입니다.
