# 반복문

## 핵심 정의
반복문은 특정 조건을 만족하는 동안 같은 작업을 여러 번 실행하게 하는 제어 구조다. 프로그램이 동일한 코드를 복사해 붙이지 않고도 여러 데이터나 여러 상황을 순차적으로 처리하게 해준다.

반복문은 "같은 규칙을 여러 대상에 적용한다"는 생각을 코드로 표현한다.

## 작동 방식
반복문은 보통 반복할 대상이나 종료 조건을 가진다. 정해진 횟수만큼 반복할 수도 있고, 조건이 참인 동안 계속 반복할 수도 있다.

예를 들어 목록 안의 항목을 하나씩 검사하거나, 사용자가 올바른 값을 입력할 때까지 요청하거나, 게임 루프처럼 매 프레임 상태를 갱신하는 작업이 반복문으로 표현된다.

## 실무적 의미
반복문은 데이터 처리, 시뮬레이션, UI 갱신, 게임 로직, 파일 처리처럼 거의 모든 프로그램에서 쓰인다. 반복문을 쓰면 같은 작업을 일관되게 적용할 수 있고, 데이터의 크기가 커져도 코드 구조를 크게 바꾸지 않아도 된다.

조건문과 함께 쓰이면 반복 중 특정 상황에서만 다른 처리를 하거나, 조건을 만족하면 반복을 멈추는 흐름을 만들 수 있다.

## 주의할 점
반복문은 종료 조건이 잘못되면 무한 반복에 빠질 수 있다. 또한 반복 안에서 너무 많은 일을 하면 성능 병목이 생길 수 있다.

중첩 반복문은 특히 주의해야 한다. 데이터가 커질수록 실행 시간이 급격히 늘 수 있으므로, 반복 횟수와 자료 구조를 함께 살펴야 한다.
