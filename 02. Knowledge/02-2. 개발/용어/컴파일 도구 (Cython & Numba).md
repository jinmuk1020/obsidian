# 컴파일 도구 (Cython & Numba)

## 핵심 설명

Cython이나 Numba와 같은 도구는 파이썬 코드에 타입 정보를 추가하거나 실행 시점에 기계어로 컴파일하여 동적 타입 언어의 성능 한계를 극복합니다. Cython은 파이썬 코드를 C 확장 모듈로 변환하여 가상 머신의 오버헤드를 직접 제거하며, Numba는 LLVM을 사용해 수치 연산 코드를 즉석에서 최적화합니다. 이러한 도구들은 특히 쉴 새 없이 돌아가는 내부 루프나 수학적 계산에서 드라마틱한 성능 향상을 제공합니다. [12-15]

## 핵심 포인트

- 정적 타입 지정을 통한 런타임 타입 검사 오버헤드 제거
- 파이썬 로직을 최적화된 기계어 또는 C 코드로 변환
- 기존 파이썬 생태계와 호환되면서도 성능 핫스팟을 효과적으로 개선
