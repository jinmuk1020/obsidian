# 조건문

## 핵심 정의
조건문은 특정 조건이 참인지 거짓인지에 따라 프로그램의 실행 흐름을 나누는 제어 구조다. 프로그램이 항상 같은 순서로만 실행되지 않고, 입력값이나 상태에 따라 다른 동작을 하게 만든다.

조건문은 "이 상황이면 이렇게 하고, 그렇지 않으면 다르게 한다"는 판단을 코드로 표현하는 방식이다.

## 작동 방식
조건문은 보통 `if`, `else if`, `else` 같은 구조로 작성된다. 먼저 조건식을 평가하고, 그 결과가 참이면 해당 블록의 코드를 실행한다. 조건이 거짓이면 다음 조건을 확인하거나, 별도의 기본 동작을 실행한다.

조건식은 비교 연산, 논리 연산, 변수의 상태를 조합해 만든다. 예를 들어 점수가 일정 기준 이상인지, 사용자가 로그인했는지, 리스트가 비어 있는지 같은 판단이 조건문으로 표현된다.

## 실무적 의미
조건문은 프로그램의 의사결정을 담당한다. 입력 검증, 예외 처리, UI 상태 변화, 게임 규칙, 권한 확인처럼 대부분의 소프트웨어 로직은 조건문을 통해 상황별 행동을 구분한다.

조건문이 명확하면 코드의 의도를 읽기 쉽다. 반대로 조건이 중첩되고 예외가 늘어나면 코드가 복잡해지기 때문에, 조건의 순서와 이름을 잘 정리해야 한다.

## 주의할 점
조건문이 많아질수록 빠뜨린 경우가 생기기 쉽다. 특히 경계값, 빈 값, 예외 상태는 별도로 확인해야 한다.

또한 조건문은 문제를 해결하는 가장 직접적인 방법이지만, 모든 분기를 조건문으로만 늘리면 유지보수가 어려워진다. 반복되는 조건이 많다면 데이터 구조나 함수 분리로 의도를 더 명확히 만들 필요가 있다.
