# FSM (Finite State Machine)

## 핵심 정의
FSM은 Finite State Machine의 약자로, 시스템이 가질 수 있는 유한한 상태와 그 상태 사이의 전이를 정의하는 모델이다. 현재 상태와 입력 이벤트에 따라 다음 상태가 결정된다.

게임 개발에서는 캐릭터 AI, UI 흐름, 전투 단계, 퀘스트 진행 상태처럼 상황이 명확히 나뉘는 로직을 표현할 때 자주 쓰인다.

## 작동 방식
FSM은 상태, 전이, 이벤트 또는 조건으로 구성된다. 예를 들어 적 AI는 `대기`, `순찰`, `추적`, `공격`, `후퇴` 같은 상태를 가질 수 있고, 플레이어 발견이나 체력 감소 같은 조건이 상태 전이를 일으킨다.

각 상태는 그 상태에서 수행할 행동과 다음 상태로 넘어갈 조건을 가진다. 이 구조는 복잡한 행동을 작은 단위로 나누어 이해하기 쉽게 만든다.

## 개발적 의미
FSM은 기획자와 개발자가 같은 로직을 공유하기 쉽게 만든다. 어떤 조건에서 어떤 상태로 넘어가는지 표나 다이어그램으로 표현할 수 있기 때문이다.

특히 게임 루프나 AI 행동처럼 시간에 따라 변하는 시스템을 설계할 때 유용하다. 상태가 명확하면 디버깅도 쉬워지고, 예외 상황을 찾기도 수월해진다.

## 주의할 점
상태가 많아지면 전이 조합이 폭발할 수 있다. 모든 예외를 상태로 추가하면 FSM은 읽기 어려운 구조가 된다.

복잡한 행동은 계층적 상태 머신이나 행동 트리 같은 구조가 더 적합할 수 있다. FSM은 단순하고 명확한 상태 전이에 강하지만, 지나치게 복합적인 의사결정을 모두 담기에는 한계가 있다.
