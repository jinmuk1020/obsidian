# 딕셔너리

## 핵심 정의
딕셔너리는 키와 값을 한 쌍으로 저장하는 자료 구조다. 순서보다 이름 붙은 접근이 중요할 때 사용하며, 특정 키를 통해 그에 대응하는 값을 빠르게 찾을 수 있다.

예를 들어 `score`, `name`, `level` 같은 키에 각각 점수, 이름, 레벨 값을 연결하면 하나의 객체나 설정값을 명확하게 표현할 수 있다.

## 작동 방식
딕셔너리는 키를 기준으로 값을 저장하고 조회한다. 같은 키는 보통 하나의 값만 가질 수 있으며, 이미 존재하는 키에 새 값을 넣으면 기존 값이 갱신된다.

프로그래밍에서는 설정값, JSON 형태의 데이터, 사용자 속성, 통계 결과처럼 이름과 값이 함께 필요한 구조를 표현할 때 많이 쓴다.

## 실무적 의미
딕셔너리는 데이터의 의미를 코드 안에 보존한다. 단순한 순서 목록은 값이 어떤 의미인지 따로 기억해야 하지만, 딕셔너리는 키가 값의 의미를 설명한다.

이 때문에 API 응답, 분석 결과, 게임 오브젝트 속성, 설정 파일처럼 구조화된 데이터를 다룰 때 유용하다.

## 주의할 점
키 이름이 일관되지 않으면 딕셔너리의 장점이 사라진다. `user_id`, `userid`, `id`처럼 같은 의미를 여러 이름으로 쓰면 오류가 생기기 쉽다.

또한 딕셔너리는 값의 구조가 자유로운 만큼, 어떤 키가 반드시 존재하는지 확인하는 로직이 필요하다. 없는 키를 조회하거나 예상과 다른 타입의 값이 들어오면 실행 오류가 발생할 수 있다.
