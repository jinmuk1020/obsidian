# 스케줄링 알고리즘

## 핵심 정의
스케줄링 알고리즘은 여러 작업 중 어떤 작업을 언제 실행할지 정하는 규칙이다. 운영체제의 프로세스, 서버 요청, 게임 루프의 작업, 비동기 I/O, 생산 시스템의 작업 순서처럼 제한된 자원을 여러 작업에 배분해야 하는 상황에서 필요하다.

스케줄링은 단순히 순서를 정하는 문제가 아니라 응답 시간, 처리량, 공정성, 우선순위, 자원 활용률 사이의 균형을 잡는 문제다.

## 작동 방식
가장 단순한 방식은 먼저 들어온 작업을 먼저 처리하는 FIFO다. 구현이 쉽고 공정해 보이지만, 긴 작업이 앞에 있으면 짧은 작업들이 오래 기다리는 문제가 생긴다.

짧은 작업 우선 방식은 평균 대기 시간을 줄일 수 있지만, 긴 작업이 계속 뒤로 밀릴 수 있다. 우선순위 스케줄링은 중요한 작업을 먼저 처리하지만, 낮은 우선순위 작업의 기아 상태를 만들 수 있다. 라운드 로빈은 시간을 잘게 나누어 작업을 번갈아 실행해 응답성을 높인다.

## 개발에서의 의미
게임 개발에서는 렌더링, 물리, AI, 네트워크, 리소스 로딩, 이벤트 처리 같은 작업의 실행 순서를 조정해야 한다. 스케줄링이 잘못되면 프레임 드랍, 입력 지연, 서버 대기열, 비동기 작업 지연이 생긴다.

서버와 운영체제에서도 스케줄링은 처리량과 응답성을 좌우한다. 어떤 알고리즘이 적합한지는 작업의 길이를 예측할 수 있는지, 실시간 응답이 필요한지, 공정성이 중요한지에 따라 달라진다.

## 주의점
하나의 스케줄링 알고리즘이 모든 상황에 최적인 것은 아니다. 처리량을 높이는 선택이 응답 시간을 악화시킬 수 있고, 공정성을 높이는 선택이 전체 효율을 낮출 수 있다. 먼저 시스템이 무엇을 가장 중요하게 여기는지 정해야 한다.
