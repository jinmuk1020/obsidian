# 신경망

## 핵심 정의
신경망은 가중치가 있는 노드와 층을 통해 입력 데이터를 변환하며 패턴을 학습하는 모델 구조다. 생물학적 신경계를 느슨하게 참고했지만, 실제로는 수학적 함수들의 조합으로 이해하는 편이 정확하다.

신경망은 입력층, 은닉층, 출력층으로 구성되며 각 층은 이전 층의 출력을 받아 새로운 표현으로 바꾼다. 여러 층을 쌓으면 단순한 특성에서 더 추상적인 특성으로 표현을 확장할 수 있다.

## 작동 방식
각 노드는 입력값에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 적용한다. 이런 계산이 여러 층을 거치면서 비선형 관계를 표현할 수 있게 된다.

학습 과정에서는 손실 함수를 정의하고, 오차 역전파를 통해 각 가중치가 손실에 얼마나 영향을 주는지 계산한다. 이후 경사 하강법으로 가중치를 조금씩 갱신한다.

## 실무적 의미
신경망은 이미지, 텍스트, 음성, 추천, 시계열처럼 복잡한 패턴을 다루는 문제에서 널리 쓰인다. 충분한 데이터와 적절한 구조가 있으면 사람이 직접 설계하기 어려운 특징을 모델이 학습할 수 있다.

딥러닝은 신경망을 여러 층으로 깊게 쌓아 더 복잡한 표현을 학습하는 접근이다. 따라서 신경망은 딥러닝의 기본 구성 단위라고 볼 수 있다.

## 주의할 점
신경망은 강력하지만 데이터와 계산 자원을 많이 요구한다. 작은 데이터에서는 과적합되기 쉽고, 결과를 설명하기 어려울 수 있다.

모델을 크게 만드는 것보다 문제에 맞는 구조, 데이터 품질, 평가 기준, 운영 비용을 함께 고려하는 것이 중요하다.
