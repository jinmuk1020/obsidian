# AUC

## 핵심 정의
AUC는 ROC 곡선 아래의 면적을 뜻하며, 이진 분류 모델이 양성과 음성을 얼마나 잘 구분하는지를 하나의 수치로 요약한다. 값이 1에 가까울수록 모델이 두 클래스를 잘 분리하고, 0.5에 가까우면 무작위 추측과 비슷하다.

AUC의 장점은 특정 임계값 하나에 묶이지 않는다는 점이다. 모델이 출력한 점수의 기준선을 바꾸면 정밀도, 재현율, 위양성률이 달라지는데, AUC는 여러 임계값에서의 전반적 구분 능력을 본다.

## 작동 방식
모델은 각 샘플에 대해 양성일 가능성을 점수로 낸다. 임계값을 높이거나 낮추면 양성으로 판정되는 샘플 수가 바뀌고, 그때마다 참양성률과 위양성률이 달라진다. 이 변화를 그린 것이 [[ROC 곡선]]이고, 그 곡선 아래 면적이 AUC다.

AUC는 순위화 능력에 가깝다. 실제 양성 샘플이 실제 음성 샘플보다 더 높은 점수를 받을 가능성이 높을수록 AUC가 커진다.

## 실무적 의미
AUC는 여러 분류 모델을 빠르게 비교할 때 유용하다. 특히 아직 운영 임계값을 정하지 않았거나, 비용 구조가 확정되지 않은 초기 모델 검토 단계에서 모델의 기본 분리력을 보는 데 적합하다.

신용 위험, 이탈 예측, 이상 탐지처럼 점수를 기준으로 후속 조치를 정하는 문제에서는 AUC가 모델 후보를 줄이는 1차 평가 지표로 자주 쓰인다.

## 주의할 점
AUC가 높다고 항상 좋은 운영 모델이라는 뜻은 아니다. 데이터가 심하게 불균형한 문제에서는 AUC가 좋아 보여도 실제로 관심 있는 소수 클래스의 정밀도는 낮을 수 있다. 이때는 [[평가지표|정밀도]], [[평가지표|재현율]], PR 곡선, 비용 기반 지표를 함께 봐야 한다.

또한 AUC는 임계값을 직접 정해주지 않는다. 운영에서는 오탐과 미탐의 비용을 고려해 별도의 기준선을 선택해야 한다.
