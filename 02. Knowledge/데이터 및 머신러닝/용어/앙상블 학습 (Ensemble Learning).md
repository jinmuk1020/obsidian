# 앙상블 학습 (Ensemble Learning)

## 핵심 정의
앙상블 학습은 여러 모델의 예측을 결합해 하나의 더 안정적이고 강한 예측을 만드는 방법이다. 단일 모델의 편향이나 변동성을 줄이고, 서로 다른 모델의 강점을 합쳐 일반화 성능을 높이는 것이 목적이다.

핵심은 모델 하나를 완벽하게 만드는 것이 아니라, 여러 모델을 충분히 다양하게 만들고 그 결과를 의미 있게 결합하는 데 있다.

## 작동 방식
대표적인 방식은 배깅과 부스팅이다. 배깅은 여러 부트스트랩 표본으로 모델을 따로 학습시킨 뒤 평균이나 투표로 결합한다. 랜덤 포레스트는 배깅을 의사결정나무에 적용한 대표 사례다.

부스팅은 이전 모델이 잘 맞히지 못한 사례에 더 집중하면서 모델을 순차적으로 추가하는 방식이다. 약한 모델을 여러 개 이어 붙여 강한 예측기를 만드는 접근이다.

## 실무적 의미
앙상블은 표 형태 데이터 예측에서 강력한 성능을 내는 경우가 많다. 단일 모델이 특정 데이터 분할에 과하게 맞는 문제를 줄이고, 예측 안정성을 높일 수 있다.

경진 대회나 실무 모델링에서도 앙상블은 성능을 끌어올리는 중요한 전략이다. 다만 운영 환경에서는 성능 향상과 해석 가능성, 추론 비용 사이의 균형을 봐야 한다.

## 주의할 점
앙상블은 성능을 높일 수 있지만 모델을 더 복잡하게 만든다. 모델 수가 많아질수록 예측 시간, 유지보수, 설명 가능성의 부담이 커진다.

또한 나쁜 모델을 무작정 많이 결합한다고 좋은 앙상블이 되지는 않는다. 모델들이 충분히 다양하면서도 각각 일정 수준 이상의 성능을 가져야 결합 효과가 생긴다.
