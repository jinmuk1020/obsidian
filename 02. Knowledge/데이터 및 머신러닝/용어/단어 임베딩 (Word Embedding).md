# 단어 임베딩 (Word Embedding)

## 핵심 정의
단어 임베딩은 단어를 고정 길이의 실수 벡터로 표현하는 자연어 처리 기법이다. 단어를 단순한 번호로 바꾸는 것이 아니라, 비슷한 문맥에서 쓰이는 단어들이 벡터 공간에서도 가깝게 놓이도록 표현한다.

컴퓨터는 텍스트를 그대로 이해하지 못한다. 단어 임베딩은 언어의 의미와 문맥 정보를 수치 데이터로 바꾸어 분류, 검색, 추천, 번역, 감성 분석 같은 작업에 사용할 수 있게 만든다.

## 작동 방식
Word2Vec 같은 알고리즘은 주변 단어를 예측하거나, 중심 단어를 주변 문맥으로부터 예측하는 방식으로 단어 벡터를 학습한다. 같은 문맥에 자주 등장하는 단어는 비슷한 벡터를 갖도록 조정된다.

벡터 공간에서는 단어 사이의 거리와 방향이 의미 관계를 어느 정도 반영한다. 예를 들어 유사한 역할을 하는 단어들은 가까운 위치에 놓이고, 특정 의미 차이는 벡터의 방향성으로 나타날 수 있다.

## 실무적 의미
단어 임베딩은 자연어를 머신러닝 모델의 입력으로 바꾸는 핵심 단계다. 임베딩이 좋으면 모델은 단어 사이의 유사성과 문맥 관계를 더 잘 활용할 수 있고, 적은 데이터에서도 더 안정적인 성능을 낼 수 있다.

RNN, LSTM, Transformer 계열 모델은 모두 텍스트를 벡터 표현으로 바꾼 뒤 그 위에서 문장 구조와 의미를 학습한다. 따라서 임베딩 품질은 자연어 처리 모델의 기초 체력에 가깝다.

## 주의할 점
단어 임베딩은 데이터의 편향을 함께 학습할 수 있다. 학습 말뭉치에 사회적 편견이나 특정 도메인의 불균형이 들어 있으면, 벡터 공간에도 그 흔적이 반영될 수 있다.

또한 단어 하나에 하나의 벡터만 주는 전통적 임베딩은 문맥에 따라 뜻이 달라지는 단어를 충분히 표현하기 어렵다. 이 한계를 줄이기 위해 문맥 기반 임베딩과 대규모 언어 모델이 발전했다.
