# 평가 함수 (Evaluation Function)

## 핵심 정의
평가 함수는 모델의 출력이나 후보 해답을 정해진 기준에 따라 점수화하는 함수다. 머신러닝에서는 예측 결과가 실제 목표에 얼마나 부합하는지 계산하고, 모델 선택이나 비교의 근거로 사용된다.

평가지표가 무엇을 볼 것인지를 말한다면, 평가 함수는 그 지표를 실제 데이터와 예측 결과에 적용해 값을 계산하는 절차에 가깝다.

## 작동 방식
평가 함수는 문제 유형에 따라 달라진다. 회귀 문제에서는 예측값과 실제값의 차이를 계산하고, 분류 문제에서는 정확도, 정밀도, 재현율, AUC 같은 지표를 계산한다.

평가 함수는 학습 중 최적화하는 손실 함수와 같을 수도 있지만 항상 같지는 않다. 손실 함수는 학습이 줄이려는 값이고, 평가 함수는 최종 목적에 맞게 성능을 판단하는 값이다.

## 실무적 의미
평가 함수는 모델 선택의 기준을 만든다. 어떤 평가 함수를 쓰느냐에 따라 좋은 모델의 정의가 달라진다. 예를 들어 사기 탐지에서는 전체 정확도보다 재현율이나 정밀도가 더 중요할 수 있다.

따라서 평가 함수는 기술적 기준이 아니라 의사결정 비용과 연결되어야 한다. 어떤 오류가 더 비싼지에 따라 모델 선택이 달라진다.

## 주의할 점
문제 정의 전에 평가 함수를 정하면 위험하다. 불균형 분류 문제에서 정확도만 보면 실패한 모델이 좋아 보일 수 있다.

또한 평가 데이터가 실제 운영 환경을 대표하지 못하면 평가 함수 값도 신뢰하기 어렵다. 검증 방식과 데이터 분포를 함께 확인해야 한다.
