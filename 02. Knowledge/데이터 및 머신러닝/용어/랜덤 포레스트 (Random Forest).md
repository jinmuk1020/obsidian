# 랜덤 포레스트 (Random Forest)

## 핵심 정의
랜덤 포레스트는 여러 개의 의사결정나무를 만들고 그 예측을 결합하는 앙상블 모델이다. 하나의 나무 판단에만 의존하지 않고, 서로 조금씩 다른 나무들의 투표나 평균을 통해 더 안정적인 예측을 만든다.

핵심 아이디어는 다양성이다. 각 나무가 같은 방식으로 실수한다면 결합의 이점이 작다. 랜덤 포레스트는 데이터 샘플과 특성 선택에 무작위성을 넣어 나무들이 서로 다른 관점을 갖게 만든다.

## 작동 방식
랜덤 포레스트는 훈련 데이터에서 부트스트랩 샘플을 여러 개 뽑아 각각의 나무를 학습시킨다. 각 분기에서도 모든 특성을 보지 않고 무작위로 선택한 일부 특성만 후보로 고려한다.

분류 문제에서는 여러 나무의 다수결로 클래스를 정하고, 회귀 문제에서는 여러 나무의 예측값을 평균낸다. 이 과정은 단일 나무보다 분산을 줄이고 과적합을 완화하는 효과가 있다.

## 실무적 의미
랜덤 포레스트는 표 형태 데이터에서 강력한 기본 모델로 자주 쓰인다. 복잡한 비선형 관계와 변수 간 상호작용을 어느 정도 자동으로 포착하며, 전처리 부담도 비교적 낮다.

또한 특성 중요도를 통해 어떤 변수가 예측에 많이 기여했는지 탐색할 수 있다. 완전한 설명 모델은 아니지만 초기 분석과 기준 모델 구축에 유용하다.

## 주의할 점
랜덤 포레스트는 단일 의사결정나무보다 해석하기 어렵다. 많은 나무가 결합되어 있기 때문에 개별 예측이 왜 나왔는지 설명하려면 별도의 해석 도구가 필요할 수 있다.

나무 수와 깊이를 크게 잡으면 계산 비용과 메모리 사용량이 늘어난다. 검증 성능이 안정적인지, 운영 환경에서 추론 시간이 감당 가능한지 함께 확인해야 한다.
