# 교차 검증

## 핵심 정의
교차 검증은 데이터를 여러 조각으로 나누어 모델을 반복적으로 학습하고 평가함으로써 일반화 성능을 추정하는 방법이다. 한 번의 학습/검증 분할에 평가가 지나치게 좌우되지 않도록 만드는 절차다.

모델의 목표는 이미 본 데이터가 아니라 앞으로 만날 데이터에서도 잘 작동하는 것이다. 교차 검증은 제한된 데이터 안에서 그 가능성을 더 안정적으로 추정하게 해준다.

## 작동 방식
가장 흔한 방식은 K-겹 교차 검증이다. 데이터를 K개의 폴드로 나누고, 매번 K-1개 폴드로 학습한 뒤 남은 1개 폴드로 검증한다. 이 과정을 K번 반복한 뒤 성능을 평균해 모델의 일반화 성능을 추정한다.

분류 문제에서는 각 폴드의 클래스 비율이 전체 데이터와 비슷하게 유지되도록 층화 교차 검증을 사용하기도 한다. 시계열 데이터처럼 순서가 중요한 경우에는 미래 정보가 과거 학습에 섞이지 않도록 별도의 분할 전략을 써야 한다.

## 실무적 의미
교차 검증은 모델 선택과 하이퍼파라미터 튜닝에서 중요하다. 검증 세트 하나의 우연한 분할에 맞춘 결정을 줄이고, 여러 검증 관점에서 일관되게 좋은 모델을 찾게 해준다.

데이터가 적을수록 교차 검증의 가치가 커진다. 별도의 검증 세트를 크게 떼어내기 어렵더라도 여러 번의 분할을 통해 평가의 불안정성을 줄일 수 있기 때문이다.

## 주의할 점
교차 검증은 평가 절차일 뿐, 데이터 누설을 자동으로 막아 주지는 않는다. 표준화, 결측치 처리, 특징 선택 같은 전처리는 각 학습 폴드 내부에서만 학습되고 검증 폴드에 적용되어야 한다.

또한 시계열, 사용자 단위 데이터, 그룹 단위 데이터에서는 무작위 분할이 오히려 잘못된 평가를 만들 수 있다. 같은 사용자나 같은 실험 단위의 데이터가 학습과 검증에 동시에 들어가면 실제보다 성능이 높게 보일 수 있다.
