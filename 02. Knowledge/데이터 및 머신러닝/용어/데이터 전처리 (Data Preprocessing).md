# 데이터 전처리 (Data Preprocessing)

## 핵심 정의
데이터 전처리는 수집된 원시 데이터를 분석이나 머신러닝 모델 학습에 적합한 형태로 정리하고 변환하는 과정이다. 결측치, 이상치, 중복 데이터, 단위 차이, 범주형 값, 텍스트 노이즈를 다루며 모델이 사용할 수 있는 입력을 만든다.

머신러닝에서 데이터의 품질은 모델 성능을 크게 좌우한다. 좋은 알고리즘도 잘못 정리된 데이터를 입력받으면 신뢰하기 어려운 결과를 낸다.

## 작동 방식
전처리에는 결측치 처리, 이상치 탐지, 중복 제거, 스케일링, 인코딩, 텍스트 정제, 특성 생성, 데이터 분할이 포함된다. 수치형 변수는 표준화나 정규화가 필요할 수 있고, 범주형 변수는 원-핫 인코딩 같은 방식으로 바꿀 수 있다.

전처리는 모델과 평가 방식에 맞춰 설계되어야 한다. 예를 들어 거리 기반 모델은 스케일 차이에 민감하고, 트리 기반 모델은 스케일링의 영향이 상대적으로 작다.

## 실무적 의미
전처리는 단순한 청소 작업이 아니라 분석 결과를 결정하는 핵심 단계다. 현실 데이터에는 입력 오류, 누락, 기준 변경, 중복, 잘못된 라벨이 섞여 있으므로 이를 어떻게 처리하느냐에 따라 모델이 배우는 패턴이 달라진다.

또한 전처리는 문제 정의와 연결된다. 결측값을 삭제할지, 별도 범주로 남길지, 중요한 신호로 볼지는 도메인 지식과 분석 목적에 따라 달라진다.

## 주의할 점
가장 중요한 위험은 데이터 누설이다. 평가 데이터의 평균이나 분포 정보를 이용해 훈련 데이터를 전처리하면 모델 성능이 실제보다 높게 보일 수 있다. 스케일러나 인코더는 훈련 데이터에 맞춰 학습하고 검증 데이터에는 적용만 해야 한다.

모든 이상치를 무조건 제거하는 것도 위험하다. 이상치가 입력 오류일 수도 있지만, 실제로 중요한 사건이나 희귀한 행동일 수도 있다. 제거하기 전에 원인과 의미를 확인해야 한다.
