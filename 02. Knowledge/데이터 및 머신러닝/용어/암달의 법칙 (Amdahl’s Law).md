# 암달의 법칙 (Amdahl’s Law)

## 핵심 정의
암달의 법칙은 작업을 병렬화해도 전체 성능 향상은 병렬화할 수 없는 순차 구간에 의해 제한된다는 법칙이다. 코어 수를 늘리거나 GPU를 추가해도 모든 코드가 동시에 실행될 수 없다면 속도 향상에는 상한이 생긴다.

핵심은 느린 부분 하나가 아니라 병렬화되지 않는 비율이다. 전체 작업 중 일부가 반드시 순서대로 실행되어야 한다면, 그 부분이 전체 실행 시간의 한계를 결정한다.

## 작동 방식
전체 작업 중 병렬 처리 가능한 비율이 높을수록 병렬화의 효과는 커진다. 반대로 순차 구간이 조금이라도 남아 있으면 프로세서를 계속 늘릴수록 추가 성능 향상은 빠르게 줄어든다.

예를 들어 작업의 90%가 병렬화 가능하고 10%가 순차 실행이라면, 이론적으로 아무리 많은 코어를 사용해도 최대 속도 향상은 10배를 넘기 어렵다. 실제 환경에서는 통신, 동기화, 메모리 이동 비용 때문에 이보다 낮아진다.

## 실무적 의미
암달의 법칙은 성능 최적화의 우선순위를 정하게 해준다. 무작정 멀티프로세싱이나 GPU를 붙이기보다 전체 시간에서 순차 구간과 병목 구간이 어디인지 먼저 측정해야 한다.

데이터 파이프라인에서는 데이터 로딩, 전처리, 직렬화, 디스크 I/O, 네트워크 전송, 메모리 이동이 병목이 될 수 있다. 계산만 빠르게 만들어도 입력과 출력이 느리면 전체 속도는 크게 오르지 않는다.

## 주의할 점
암달의 법칙은 병렬 처리의 한계를 설명하지만, 병렬 처리가 쓸모없다는 뜻은 아니다. 병렬화 가능한 비율이 충분히 크고 오버헤드가 작다면 큰 이득을 얻을 수 있다.

또한 최적화 후에는 병목이 이동한다. 계산을 빠르게 만들면 다음에는 데이터 로딩이나 메모리 전송이 병목이 될 수 있으므로 측정과 개선을 반복해야 한다.
