# 서치 콘솔 (Search Console)

## 핵심 정의
서치 콘솔은 검색 엔진에서 사이트가 어떻게 노출되고 클릭되는지 확인하는 분석 도구다. 검색어, 노출수, 클릭수, 클릭률, 평균 순위 같은 데이터를 통해 사용자가 어떤 검색 의도로 사이트에 도달하는지 파악한다.

일반 웹 로그만으로는 검색어가 가려지는 경우가 많다. 서치 콘솔은 이 빈틈을 보완해 자연 검색 유입의 실제 질문과 성과를 보여준다.

## 작동 방식
서치 콘솔은 검색 결과 페이지에서 발생한 노출과 클릭을 기준으로 데이터를 제공한다. 특정 페이지가 어떤 검색어에서 노출되는지, 순위가 떨어지는지, 클릭률이 낮은지, 색인 문제가 있는지를 확인할 수 있다.

이 데이터는 광고 성과 데이터와 다르다. 서치 콘솔은 자연 검색의 발견 가능성과 검색 의도를 보는 도구이고, GA 같은 웹 분석 도구는 유입 이후의 행동과 전환을 보는 도구에 가깝다.

## 설계상 의미
콘텐츠 기획에서는 서치 콘솔을 통해 사용자가 실제로 쓰는 언어를 확인할 수 있다. 내부에서 정한 용어와 사용자가 검색하는 표현이 다르면 제목, 설명, 정보 구조를 조정해야 한다.

서비스 분석에서는 검색어와 랜딩 페이지를 함께 봐야 한다. 유입은 많지만 이탈이 높다면 검색 의도와 페이지 내용이 맞지 않을 수 있다.

## 주의할 점
서치 콘솔 데이터는 검색 노출과 클릭의 데이터이지, 사용자의 전체 행동 데이터가 아니다. 검색 이후의 체류, 전환, 반복 방문은 별도의 웹 분석 데이터와 함께 봐야 한다.

또한 평균 순위는 검색어, 위치, 개인화, 기기 환경에 따라 달라질 수 있으므로 단일 숫자만으로 성과를 판단하면 안 된다.
