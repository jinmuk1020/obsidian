# NumPy

## 핵심 정의
NumPy는 파이썬에서 다차원 배열과 수치 연산을 효율적으로 다루기 위한 핵심 라이브러리다. 파이썬 리스트보다 계산에 특화된 배열 구조를 제공하며, 데이터 분석과 머신러닝에서 수치 데이터를 표현하는 기본 기반이 된다.

NumPy가 중요한 이유는 파이썬의 생산성과 저수준 수치 연산의 속도를 연결해주기 때문이다. 사용자는 파이썬 문법으로 작업하지만, 실제 무거운 계산은 C로 구현된 빠른 연산 루틴이 처리한다.

## 작동 방식
NumPy의 중심 구조는 `ndarray`다. 이 배열은 같은 타입의 값을 연속된 메모리 구조에 저장하기 때문에 반복문으로 하나씩 계산하는 방식보다 훨씬 빠르게 연산할 수 있다.

또한 NumPy는 벡터화 연산을 지원한다. 벡터화는 데이터 전체에 같은 연산을 한 번에 적용하는 방식으로, 파이썬 반복문을 줄이고 배열 단위 계산을 가능하게 한다. 브로드캐스팅을 이용하면 서로 다른 형태의 배열도 규칙에 맞게 확장되어 계산된다.

## 실무적 의미
NumPy는 [[Pandas]], [[scikit-learn]], 딥러닝 프레임워크 같은 데이터 도구들의 바닥에 깔린 수치 계산 언어에 가깝다. 데이터 전처리, 행렬 계산, 통계량 산출, 모델 입력 구성 같은 작업에서 반복적으로 쓰인다.

머신러닝 모델을 이해할 때도 NumPy적 사고가 도움이 된다. 특성 행렬, 가중치 벡터, 손실 함수, 경사 계산은 결국 배열과 선형대수 연산으로 표현되는 경우가 많다.

## 주의할 점
NumPy 배열은 하나의 배열 안에서 같은 데이터 타입을 전제로 한다. 문자열, 숫자, 결측값이 섞인 테이블 데이터를 직접 다루기에는 [[Pandas]]가 더 적합할 수 있다.

또한 벡터화가 항상 메모리 효율적인 것은 아니다. 중간 배열이 많이 생기면 계산은 빨라도 메모리를 크게 사용할 수 있으므로, 대용량 데이터에서는 배열 크기와 복사 여부를 확인해야 한다.
