# 정규화

## 핵심 정의
정규화는 데이터의 값 범위나 스케일을 일정한 기준으로 맞추는 전처리 과정이다. 변수마다 단위와 크기가 크게 다르면 모델이 특정 변수의 규모에 과도하게 영향을 받을 수 있기 때문에, 값을 비교 가능한 범위로 바꾼다.

머신러닝에서 정규화는 거리 기반 모델, 기울기 기반 최적화, 신경망 학습에서 특히 중요하다.

## 작동 방식
대표적인 방식은 최소-최대 정규화와 표준화다. 최소-최대 정규화는 값을 0과 1 사이 범위로 바꾸고, 표준화는 평균을 0, 표준편차를 1로 맞춘다.

어떤 방식을 선택할지는 데이터 분포와 모델 특성에 따라 달라진다. 이상치가 많으면 최소-최대 정규화가 극단값에 크게 영향을 받을 수 있다.

## 실무적 의미
정규화는 모델 학습의 안정성과 속도를 높인다. 경사 하강법 기반 모델은 변수 스케일이 비슷할수록 손실 표면을 더 효율적으로 탐색할 수 있다.

k-최근접 이웃처럼 거리 계산을 쓰는 모델에서는 정규화가 특히 중요하다. 단위가 큰 변수가 거리를 지배하면 실제로 중요한 변수의 영향이 묻힐 수 있다.

## 주의할 점
정규화 기준은 훈련 데이터에서만 학습해야 한다. 전체 데이터의 평균이나 최소, 최대를 먼저 계산한 뒤 분할하면 평가 데이터의 정보가 훈련 과정에 섞이는 데이터 누설이 생긴다.

또한 모든 모델에 정규화가 같은 정도로 필요한 것은 아니다. 트리 기반 모델은 스케일 변화에 상대적으로 덜 민감하지만, 파이프라인 일관성을 위해 전처리 기준은 명확히 기록해야 한다.
