# 활성화 함수 (Activation Function)

## 핵심 정의
활성화 함수는 신경망의 각 노드가 입력의 가중합을 받은 뒤 다음 층으로 어떤 값을 보낼지 결정하는 함수다. 신경망에 비선형성을 넣어 복잡한 패턴을 학습할 수 있게 만든다.

활성화 함수가 없으면 여러 층을 쌓아도 결국 하나의 선형 변환과 크게 다르지 않다. 딥러닝의 표현력은 활성화 함수가 만드는 비선형 변환에 크게 의존한다.

## 작동 방식
각 노드는 입력값에 가중치를 곱하고 편향을 더한 뒤 활성화 함수를 적용한다. 대표적인 활성화 함수에는 시그모이드, tanh, ReLU가 있다.

시그모이드는 값을 0과 1 사이로 압축하고, tanh는 -1과 1 사이로 압축한다. ReLU는 0보다 작은 값은 0으로, 양수는 그대로 통과시켜 깊은 신경망에서 널리 쓰인다.

## 실무적 의미
활성화 함수 선택은 학습 안정성과 성능에 영향을 준다. ReLU 계열은 계산이 단순하고 기울기 소실 문제를 완화해 많은 딥러닝 모델에서 기본 선택지로 쓰인다.

출력층의 활성화 함수는 문제 유형과 연결된다. 이진 분류에서는 시그모이드, 다중 분류에서는 소프트맥스가 자주 사용된다.

## 주의할 점
활성화 함수가 잘못 선택되면 학습이 느려지거나 기울기가 사라질 수 있다. 특히 시그모이드와 tanh는 입력이 극단적으로 커지면 기울기가 작아지는 포화 문제가 있다.

또한 활성화 함수는 손실 함수, 초기화, 정규화, 학습률과 함께 작동한다. 하나만 바꿔서 결과를 해석하기보다 전체 학습 설정을 함께 봐야 한다.
