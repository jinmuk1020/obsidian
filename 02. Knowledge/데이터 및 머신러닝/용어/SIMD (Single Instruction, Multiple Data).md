# SIMD (Single Instruction, Multiple Data)

## 핵심 정의

SIMD는 하나의 명령으로 여러 데이터에 같은 연산을 동시에 적용하는 병렬 처리 방식이다. 반복되는 수치 계산을 데이터 단위로 묶어 처리해 CPU나 GPU의 계산 효율을 높인다.

벡터 계산, 이미지 처리, 선형대수, 머신러닝 계산에서 SIMD는 성능 향상의 중요한 기반이 된다.

## 작동 방식

일반적인 스칼라 연산은 한 번에 하나의 값에 명령을 적용한다. SIMD는 여러 값을 하나의 벡터 레지스터에 담고 같은 덧셈, 곱셈, 비교 연산을 동시에 수행한다.

[[NumPy와 벡터화 (Vectorization)]]가 빠른 이유 중 하나도 파이썬 반복문 대신 저수준 배열 연산과 SIMD 친화적인 처리를 활용하기 때문이다.

## 개발상의 의미

SIMD는 알고리즘을 "한 값씩 처리"하는 방식에서 "배열 단위로 처리"하는 방식으로 바꾸게 한다. 데이터가 크고 같은 연산이 반복될수록 효과가 커진다.

머신러닝에서는 행렬 곱, 합성곱, 벡터 연산이 대량으로 발생하므로 SIMD와 벡터화는 성능의 핵심이다.

## 주의할 점

SIMD는 데이터 배치가 중요하다. 데이터가 메모리에 흩어져 있거나 조건 분기가 많으면 병렬 처리 이점이 줄어든다.

따라서 SIMD 성능을 얻으려면 배열 구조, dtype, 메모리 접근 패턴, 불필요한 중간 객체 생성을 함께 고려해야 한다.

## 연결 개념

- [[NumPy와 벡터화 (Vectorization)]] | 벡터화는 SIMD 친화적인 계산 표현 방식이다.
- multiprocessing을 통한 병렬 처리 | 프로세스 병렬성과 SIMD는 서로 다른 층위의 병렬화다.
- 메모리 지역성 | 연속된 데이터 배치가 SIMD 효율을 높인다.
- 캐시 미스 | 비효율적인 데이터 접근은 SIMD의 이점을 줄인다.
