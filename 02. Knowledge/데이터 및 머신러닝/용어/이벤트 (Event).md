# 이벤트 (Event)

## 핵심 정의
이벤트는 시스템이나 사용자가 특정 시점에 수행한 의미 있는 행동 또는 발생한 상태 변화를 기록한 데이터 단위다. 클릭, 로그인, 구매, 페이지 조회, 오류 발생, 레벨 완료처럼 시간과 맥락을 가진 관측값이다.

데이터 분석에서 이벤트는 행동 데이터를 구성하는 기본 입자다. 이벤트가 잘 정의되어야 사용자 여정, 전환, 이탈, 퍼널, 실험 결과를 신뢰할 수 있다.

## 작동 방식
이벤트 데이터는 보통 이벤트 이름, 발생 시각, 사용자 또는 세션 식별자, 속성 값을 함께 가진다. 예를 들어 `purchase_completed` 이벤트에는 상품 ID, 가격, 결제 수단, 캠페인 정보가 붙을 수 있다.

이벤트는 단독으로도 의미가 있지만, 순서와 맥락을 함께 볼 때 더 큰 가치를 가진다. 사용자가 어떤 경로로 들어와 어떤 행동을 거쳐 전환했는지 분석할 수 있기 때문이다.

## 실무적 의미
이벤트 설계는 제품 분석과 머신러닝의 기반이다. 어떤 행동을 이벤트로 남길지, 어떤 속성을 함께 저장할지에 따라 이후 분석 가능한 질문이 결정된다.

좋은 이벤트 체계는 목적과 지표에서 출발한다. 모든 행동을 무작정 기록하는 것이 아니라, 의사결정에 필요한 행동을 일관된 이름과 스키마로 기록해야 한다.

## 주의할 점
이벤트 이름과 속성 정의가 자주 바뀌면 장기 추세를 비교하기 어렵다. 동일한 행동이 여러 이름으로 기록되거나, 같은 이름이 다른 의미로 쓰이면 데이터 품질이 무너진다.

또한 이벤트는 개인정보와 연결될 수 있으므로 수집 범위와 보관 기준을 신중히 정해야 한다.
