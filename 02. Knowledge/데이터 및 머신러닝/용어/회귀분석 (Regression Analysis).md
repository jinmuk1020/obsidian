# 회귀분석 (Regression Analysis)

## 핵심 정의
회귀분석은 하나의 결과 변수와 하나 이상의 설명 변수 사이의 관계를 수학적 함수로 모델링하는 분석 방법이다. 주로 연속적인 값을 예측하거나, 어떤 변수가 결과와 얼마나 관련되는지 설명하는 데 사용된다.

회귀분석은 “X가 변할 때 Y가 어떻게 변하는가”를 다룬다. 단순 회귀는 하나의 설명 변수를 사용하고, 다중 회귀는 여러 설명 변수를 함께 사용한다.

## 작동 방식
회귀분석은 실제 관측값과 모델 예측값의 차이를 줄이는 방향으로 계수를 찾는다. 기본적인 선형 회귀에서는 오차 제곱합을 최소화하는 직선을 찾는 최소제곱법이 자주 쓰인다.

모델을 만들면 설명 변수의 값으로 결과 변수를 예측할 수 있고, 각 계수의 방향과 크기를 통해 변수 간 관계를 해석할 수 있다. 다만 이 관계는 모델 가정 안에서의 관계이지, 곧바로 인과관계를 증명하지는 않는다.

## 실무적 의미
회귀분석은 매출, 수요, 가격, 성과 지표처럼 수치형 결과를 예측하는 데 널리 쓰인다. 또한 어떤 요인이 결과와 얼마나 관련되는지 설명해야 할 때 기초적인 분석 언어가 된다.

비즈니스에서는 캠페인 성과, 가격 변화, 고객 특성, 운영 지표와 결과 사이의 관계를 파악하는 데 활용할 수 있다.

## 주의할 점
회귀계수가 있다고 해서 반드시 인과 효과가 있다는 뜻은 아니다. 누락 변수, 다중공선성, 이상치, 비선형 관계가 있으면 해석이 크게 흔들릴 수 있다.

또한 학습 데이터 범위를 벗어난 외삽 예측은 위험하다. 모델이 본 적 없는 구간에서도 같은 추세가 유지된다고 보장할 수 없다.
