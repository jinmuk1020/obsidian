# 표본편향 (Sample Bias)

## 핵심 정의
표본편향은 분석에 사용한 표본이 모집단을 공정하게 대표하지 못하고 특정 방향으로 치우친 상태다. 표본이 충분히 많아도 수집 방식이 치우쳐 있으면 분석 결과는 모집단의 실제 모습을 반영하지 못한다.

머신러닝에서는 훈련 데이터나 테스트 데이터가 실제 운영 환경을 대표하지 못할 때 표본편향이 문제가 된다. 모델은 데이터에 있는 세계만 배우기 때문에, 빠진 집단이나 과대표집된 집단에 대해 잘못된 판단을 내릴 수 있다.

## 작동 방식
표본편향은 무작위 추출이 깨지거나, 특정 사용자가 더 쉽게 관찰되거나, 특정 범주가 데이터 수집 과정에서 빠질 때 생긴다. 예를 들어 온라인 설문만 사용하면 온라인 접근성이 낮은 사람들의 의견이 배제될 수 있다.

모델 학습에서는 특정 클래스가 과도하게 많거나 적으면 모델이 다수 집단에 유리하게 학습된다. 테스트 데이터까지 같은 방식으로 편향되어 있으면 문제를 발견하기도 어렵다.

## 실무적 의미
표본편향은 분석의 신뢰도를 근본적으로 무너뜨린다. 데이터가 많다는 사실만으로 대표성이 보장되지 않으며, 데이터가 어떻게 수집되었는지 확인해야 한다.

실무에서는 모집단 정의, 표본 추출 방식, 누락 집단, 클래스 비율, 훈련/테스트 데이터의 분포 차이를 점검해야 한다. 필요하면 재표본추출, 가중치 부여, 층화 추출, 추가 데이터 수집을 고려한다.

## 주의할 점
표본편향은 모델 성능 지표를 좋아 보이게 만들 수 있다. 테스트 데이터가 실제 환경보다 쉬운 표본이면 운영 성능은 급격히 떨어진다.

또한 편향은 기술적 문제만이 아니라 윤리적 문제이기도 하다. 특정 집단이 데이터에서 누락되면 서비스 품질과 의사결정이 그 집단에 불리하게 작동할 수 있다.
