# 필터 (Filter)

## 핵심 정의
필터는 데이터나 이벤트가 다음 단계로 넘어가기 전에 특정 조건에 따라 포함하거나 제외하는 장치다. 분석에서는 불필요한 데이터, 내부 트래픽, 스팸, 관심 범위 밖의 사례를 걸러 목적에 맞는 데이터만 남기기 위해 사용한다.

필터는 단순한 검색 조건과 다르다. 수집이나 전처리 단계에서 적용되는 필터는 이후 데이터 자체를 바꾸므로 분석 결과의 기준과 범위를 결정한다.

## 작동 방식
필터는 포함 조건과 제외 조건으로 작동한다. 특정 날짜 범위, 사용자 집단, 국가, 캠페인, 이벤트 이름, URL 패턴을 기준으로 데이터를 남기거나 제거할 수 있다.

분석 도구에서는 보고서 화면에서 임시 필터를 적용할 수도 있고, 데이터 수집 단계에서 영구적으로 필터를 적용할 수도 있다. 후자의 경우 원본 보존과 검증이 특히 중요하다.

## 실무적 의미
좋은 필터는 분석 데이터의 신호를 선명하게 만든다. 내부 테스트 트래픽, 봇 트래픽, 중복 이벤트가 섞이면 실제 사용자 행동을 잘못 해석할 수 있다.

필터는 의사결정의 범위를 명확히 한다. 전체 데이터를 보는 대신 목적에 맞는 세그먼트와 조건을 정하면 문제 원인과 개선 대상을 더 빠르게 찾을 수 있다.

## 주의할 점
필터는 강력하지만 위험하다. 원본 수집 단계에서 잘못 적용하면 필요한 데이터가 영구적으로 사라질 수 있다. 그래서 보통 원본 보기를 보존하고, 테스트 보기에서 필터를 검증한 뒤 운영 보기에 적용하는 방식이 안전하다.

또한 필터 기준이 바뀌면 기간 비교가 왜곡된다. 전후 지표를 비교할 때 같은 필터 기준이 적용되었는지 확인해야 한다.
