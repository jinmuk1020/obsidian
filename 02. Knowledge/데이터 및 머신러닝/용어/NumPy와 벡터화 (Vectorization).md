# NumPy와 벡터화 (Vectorization)

## 핵심 정의

NumPy는 파이썬에서 다차원 배열과 빠른 수치 계산을 제공하는 라이브러리이고, 벡터화는 파이썬 반복문 대신 배열 단위 연산으로 계산을 표현하는 방식이다. 벡터화를 사용하면 내부의 최적화된 C 코드와 하드웨어 친화적 연산을 활용할 수 있다.

즉, 원소를 하나씩 처리하는 대신 배열 전체에 같은 연산을 한 번에 적용한다.

## 작동 방식

NumPy 배열은 일반 파이썬 리스트보다 메모리에 더 연속적으로 저장된다. 이 구조는 CPU 캐시와 [[SIMD (Single Instruction, Multiple Data)]] 연산에 유리하다.

예를 들어 두 리스트의 원소를 반복문으로 더하는 대신, 두 NumPy 배열을 `a + b`로 더하면 반복 제어는 파이썬이 아니라 최적화된 저수준 코드에서 처리된다.

## 실무적 의미

대규모 데이터 처리와 과학 계산에서 NumPy는 기본 인프라다. 행렬 연산, 통계 계산, 시뮬레이션, 이미지 처리, 머신러닝 전처리에서 반복문을 줄이고 계산 속도를 높인다.

또한 [[Pandas]]와 [[scikit-learn]] 같은 라이브러리의 기반이 되므로, NumPy 배열의 구조와 브로드캐스팅, dtype, shape 개념을 이해하면 데이터 분석 도구를 더 안정적으로 쓸 수 있다.

## 주의할 점

벡터화가 항상 최적은 아니다. 중간 배열이 과도하게 만들어지면 메모리 사용량이 커질 수 있고, 조건 분기가 복잡한 작업은 벡터화 표현이 오히려 읽기 어려울 수 있다.

또한 shape이 맞지 않는 연산은 브로드캐스팅으로 예상치 못한 결과를 만들 수 있다. 계산 전에 배열 차원과 dtype을 확인해야 한다.

## 연결 개념

- [[SIMD (Single Instruction, Multiple Data)]] | 벡터화가 활용하는 데이터 병렬 처리 방식과 연결된다.
- [[Pandas]] | NumPy 위에서 표 형태의 데이터 분석 기능을 제공한다.
- 메모리 지역성 | 연속된 메모리 배치가 계산 효율을 높인다.
- 캐시 미스 | 데이터 접근이 비효율적일 때 성능을 떨어뜨린다.
