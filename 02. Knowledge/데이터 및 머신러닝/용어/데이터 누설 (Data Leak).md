# 데이터 누설 (Data Leak)

## 핵심 정의
데이터 누설은 모델 학습 과정에 실제 예측 시점에는 알 수 없는 정보가 섞여 들어가 성능 평가가 비정상적으로 좋아지는 현상이다. 테스트 데이터의 정보나 미래 정보가 훈련 단계에 들어가면 모델은 현실에서 쓸 수 없는 단서를 학습한다.

겉으로는 정확도가 높아 보이지만, 운영 환경에 배포하면 성능이 급격히 떨어진다.

## 작동 방식
데이터 누설은 여러 방식으로 발생한다. 전체 데이터의 평균과 표준편차로 전처리한 뒤 훈련/테스트를 나누거나, 미래에 확정되는 값을 입력 피처로 넣거나, 중복 샘플이 훈련과 검증 세트에 동시에 들어가는 경우가 있다.

시계열 문제에서는 시간 순서를 무시한 무작위 분할이 특히 위험하다. 미래의 패턴이 과거 학습에 새어 들어갈 수 있기 때문이다.

## 데이터 분석상의 의미
데이터 누설은 모델 신뢰성을 무너뜨리는 치명적 오류다. 과적합보다 더 위험한 점은 성능 평가 단계에서 문제가 잘 드러나지 않는다는 것이다.

분석가는 모델링 전에 “예측 시점에 이 정보를 정말 알 수 있는가”를 기준으로 모든 변수를 점검해야 한다.

## 주의점
누설은 의도적인 실수보다 분석 파이프라인의 순서 문제에서 자주 생긴다. 전처리, 피처 엔지니어링, 샘플링, 교차 검증은 반드시 훈련 데이터 기준으로 수행하고 검증 데이터에는 독립적으로 적용해야 한다.
