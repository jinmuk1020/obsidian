# 지도 학습 (Supervised Learning)

## 핵심 설명

지도 학습은 입력 데이터에 대해 적절한 출력이 무엇인지 정답(라벨)이 주어진 상태에서 학습하여 결과를 예측하는 방법입니다 [4]. 이는 연속적인 수치를 예측하는 '회귀' 문제와 데이터를 특정 카테고리로 나누는 '분류' 문제로 크게 구분됩니다 [5-7]. 훈련 데이터를 사용해 모델의 매개 변수를 최적화하고, 이를 테스트 데이터로 평가하여 미지의 입력에 대한 예측력을 극대화하는 과정을 거칩니다 [7-9]. 확률적 개념을 도입하여 모호성을 근사하거나 복잡한 비선형 관계를 학습하는 데 매우 효과적입니다 [7, 10, 11].

## 핵심 포인트

- 입력 데이터와 정답(라벨) 쌍을 이용한 학습 [4]
- 연속적 수치 예측인 회귀와 범주형 예측인 분류 [5-7]
- 모델 선택과 검증을 위한 데이터 분할 필요 [8, 9]

## 중요성

명확한 정답이 있는 문제 상황에서 데이터를 가장 효율적으로 학습하여 높은 예측 정확도를 달성하게 해줍니다 [6, 7].
