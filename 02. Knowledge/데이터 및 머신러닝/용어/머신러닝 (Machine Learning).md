# 머신러닝 (Machine Learning)

## 핵심 정의
머신러닝은 사람이 모든 규칙을 직접 코딩하지 않고, 데이터로부터 패턴과 판단 규칙을 학습해 예측이나 의사결정을 수행하게 하는 방법이다. 입력과 정답, 또는 데이터 자체의 구조를 이용해 모델의 파라미터를 조정한다.

전통적인 프로그래밍이 사람이 규칙을 쓰고 컴퓨터가 실행하는 방식이라면, 머신러닝은 데이터와 목표를 주고 모델이 규칙에 가까운 표현을 찾아가게 하는 방식이다.

## 작동 방식
머신러닝 모델은 훈련 데이터에서 반복되는 구조를 학습한다. 지도 학습은 정답 라벨이 있는 데이터로 예측 함수를 만들고, 비지도 학습은 라벨 없이 데이터의 구조를 찾는다. 딥러닝은 신경망을 여러 층으로 쌓아 복잡한 표현을 학습하는 머신러닝의 한 분야다.

학습된 모델은 새 입력에 대해 예측을 만든다. 이때 중요한 것은 훈련 데이터에서의 성능이 아니라, 아직 보지 못한 데이터에서도 작동하는 일반화 능력이다.

## 실무적 의미
머신러닝은 분류, 회귀, 추천, 이상 탐지, 자연어 처리, 이미지 인식, 수요 예측 같은 문제에 쓰인다. 문제 정의, 데이터 수집, 전처리, 학습, 검증, 배포, 모니터링이 하나의 흐름으로 이어진다.

좋은 머신러닝 프로젝트는 모델 선택보다 문제 정의와 데이터 품질에서 승부가 갈린다. 무엇을 예측할지, 예측 결과가 어떤 행동으로 연결될지, 성공을 어떤 지표로 볼지가 먼저 정리되어야 한다.

## 주의할 점
머신러닝은 자동화된 판단 도구이지 문제 정의를 대신하는 도구가 아니다. 데이터가 편향되어 있거나 목표가 잘못 정의되어 있으면 좋은 알고리즘도 잘못된 결론을 만든다.

또한 높은 정확도만으로 충분하지 않을 수 있다. 해석 가능성, 비용, 지연 시간, 운영 안정성, 개인정보와 윤리 문제까지 함께 고려해야 한다.
