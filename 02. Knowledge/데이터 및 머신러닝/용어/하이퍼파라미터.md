# 하이퍼파라미터

## 핵심 정의
하이퍼파라미터는 모델이 데이터로부터 직접 학습하지 않고, 학습 전에 사용자가 정하거나 탐색해야 하는 설정값이다. 학습률, 배치 크기, 트리 깊이, 정규화 강도, 군집 수처럼 학습 과정과 모델 구조를 제어한다.

모델 파라미터가 학습 결과라면, 하이퍼파라미터는 그 학습이 어떤 방식으로 진행될지 정하는 조건이다.

## 작동 방식
하이퍼파라미터는 검증 성능을 기준으로 조정한다. 여러 후보 설정을 실험하고, 교차 검증이나 검증 세트 성능을 비교해 적절한 값을 찾는다.

탐색 방식에는 수동 조정, 그리드 서치, 랜덤 서치, 베이지안 최적화 등이 있다. 문제 크기와 비용에 따라 적절한 방식을 선택한다.

## 실무적 의미
하이퍼파라미터는 모델 성능과 안정성에 큰 영향을 준다. 같은 알고리즘과 데이터라도 학습률이나 모델 깊이가 달라지면 결과가 크게 달라질 수 있다.

그러나 하이퍼파라미터 튜닝은 모델링의 마지막 마감 작업에 가깝다. 데이터 품질, 문제 정의, 특성 공학이 부실하면 튜닝만으로 좋은 모델을 만들기 어렵다.

## 주의할 점
검증 세트에 과도하게 맞추는 것도 과적합이다. 너무 많은 하이퍼파라미터 실험을 반복하면 검증 성능이 우연히 좋은 설정을 고를 수 있다.

튜닝 결과는 실험 기록과 함께 남겨야 한다. 어떤 범위를 탐색했고 어떤 기준으로 선택했는지 기록하지 않으면 재현하기 어렵다.
