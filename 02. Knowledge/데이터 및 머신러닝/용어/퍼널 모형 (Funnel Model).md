# 퍼널 모형 (Funnel Model)

## 출처

- Source ID: `81fc5ee4-2e84-48f2-b669-aee07d3a4e50`
- Notebook: 내 정수

## 핵심 설명

방문에서 구매에 이르기까지 사용자가 거치는 여정을 입구가 넓고 출구가 좁은 '깔때기'에 비유하여 분석하는 방법입니다 [12]. 사용자가 각 단계를 거치며 이탈하는 지점을 시나리오별로 시각화하여, 어디에서 병목 현상이 발생하는지 진단하는 데 핵심적인 역할을 합니다 [12, 13]. 데이터 분석의 궁극적인 목적은 이 퍼널의 입구와 출구를 넓혀 비즈니스 성과를 극대화하는 개선안을 찾는 것입니다 [12].

## 핵심 포인트

- 유입에서 전환까지의 단계별 사용자 흐름을 깔때기 형태로 시각화함 [12, 13]
- 특정 단계에서 발생하는 이탈 경로를 찾아내어 문제의 원인을 분석함 [13]
- 실질적인 개선 행동을 이끌어내는 '액셔너블 인사이트'를 도출함 [13]

## 중요성

비즈니스 성과를 저해하는 '약한 고리'를 명확히 짚어주어 데이터에 근거한 구체적인 서비스 개선을 가능하게 합니다 [13, 14].
