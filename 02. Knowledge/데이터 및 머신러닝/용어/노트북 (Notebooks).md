# 노트북 (Notebooks)

## 핵심 정의
노트북은 코드, 실행 결과, 시각화, 설명 문서를 하나의 문서 안에서 함께 다루는 대화형 분석 환경이다. Jupyter Notebook, Google Colab, Kaggle Notebook처럼 브라우저 기반으로 실행되는 도구가 대표적이다.

데이터 분석에서는 탐색, 실험, 설명이 자주 오간다. 노트북은 코드를 실행하면서 바로 결과를 보고, 그 해석을 마크다운으로 기록할 수 있어 분석 사고의 흐름을 보존하기 좋다.

## 작동 방식
노트북은 셀 단위로 구성된다. 코드 셀은 파이썬이나 R 같은 언어를 실행하고, 마크다운 셀은 설명, 수식, 이미지, 링크를 담는다. 사용자는 셀을 순서대로 실행하면서 데이터 로딩, 전처리, 분석, 모델링, 시각화를 단계적으로 진행한다.

클라우드 노트북 환경은 로컬 설치 부담을 줄여 준다. GPU나 TPU 같은 계산 자원을 일정 한도 안에서 제공하기도 하며, 데이터셋과 실험 결과를 공유하기 쉽게 만든다.

## 실무적 의미
노트북은 빠른 탐색적 데이터 분석과 실험 기록에 강하다. 그래프를 그려 보고, 가설을 세우고, 모델을 바꿔 보며 결과를 비교하는 과정이 하나의 문서에 남는다.

반면 운영 코드나 반복 실행 파이프라인은 노트북만으로 관리하기 어렵다. 실험 단계에서는 노트북이 유용하지만, 검증된 로직은 모듈화된 스크립트나 파이프라인으로 옮기는 편이 안정적이다.

## 주의할 점
노트북은 셀 실행 순서가 문서 위아래 순서와 달라질 수 있다. 이 때문에 처음부터 끝까지 다시 실행했을 때 같은 결과가 나오는지 확인하지 않으면 숨은 상태 의존성이 생긴다.

또한 노트북에 대용량 출력, 임시 파일 경로, 개인 인증 정보가 섞이지 않도록 주의해야 한다. 공유용 노트북은 재현 가능한 입력과 최소한의 출력만 남기는 편이 좋다.
