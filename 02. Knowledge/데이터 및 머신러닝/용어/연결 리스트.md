# 연결 리스트

## 한 문장 정의
각 원소가 다음 원소의 위치를 가리키는 노드 기반 선형 구조입니다.

## 상세 정의
`연결 리스트`은/는 [[데이터|데이터]] 수집, 분석, 모델링, 알고리즘 설계, 성능 평가 또는 비즈니스 의사결정의 어느 지점에서 작동하는 개념입니다. 이 노트는 바탕화면 원본 PDF에서 직접 추출한 텍스트를 근거로 작성했습니다.

## 문서 안에서의 맥락
이 개념은 아래 원본 자료에서 반복적으로 발견되었으며, 각 자료의 문제의식에 따라 분석 플랫폼, 통계 추론, [[머신러닝 (Machine Learning)|머신러닝]] 모델링, 알고리즘 효율, [[파이썬 (Python)|파이썬]] 성능, 경진대회 실무와 연결됩니다.

## 작동 메커니즘
- 문제 정의와 측정 기준이 먼저 정해집니다.
- 관련 데이터를 수집하고 전처리합니다.
- 분석 또는 모델링 절차를 적용합니다.
- 결과를 평가지표나 비즈니스 목표와 비교합니다.
- 해석 결과를 바탕으로 개선, 자동화, 의사결정에 반영합니다.

## 설계/비즈니스상 중요도
이 개념을 정확히 이해하면 데이터 기반 의사결정의 신뢰도를 높이고, 잘못된 측정/모델 선택/성능 해석으로 인한 실행 오류를 줄일 수 있습니다.
## 원문 근거 예시
- 별도의 연결 리스트로 저장하는 체이닝(chaining) 방식과 충돌 발생 시 미리 정해진 알고리즘을 사용해 다른 버킷을 찾아서 키/값을
- (연결 리스트)에 들어갈 수도 있기 때문에 개방 해싱(open hashing)이라고 부른다.
- 2장에서는 선형 데이터 구조인 배열, 연결 리스트, 스택, 큐를 설명한다.
- 이 때문에 연결 리스트linked list(링크드 리스트라고도 한다)는 메모리
