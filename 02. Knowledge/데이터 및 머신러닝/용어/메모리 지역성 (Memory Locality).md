# 메모리 지역성 (Memory Locality)

## 핵심 정의
메모리 지역성은 프로그램이 짧은 시간 동안 특정 메모리 영역이나 그 주변 데이터를 반복적으로 참조하는 경향이다. CPU 캐시는 이 성질을 이용해 자주 쓰일 데이터를 느린 메인 메모리보다 가까운 곳에 미리 가져온다.

지역성이 좋으면 CPU가 메모리를 기다리는 시간이 줄어들고 계산 성능이 높아진다. 데이터 분석과 머신러닝처럼 대량 배열을 처리하는 작업에서는 이 차이가 크게 드러날 수 있다.

## 작동 방식
메모리 지역성은 시간적 지역성과 공간적 지역성으로 나뉜다. 시간적 지역성은 방금 접근한 데이터를 곧 다시 접근할 가능성이 높다는 뜻이고, 공간적 지역성은 어떤 주소에 접근하면 그 주변 주소에도 곧 접근할 가능성이 높다는 뜻이다.

배열처럼 연속된 메모리를 순서대로 읽는 구조는 공간적 지역성이 좋다. 반대로 연결 리스트처럼 노드가 메모리 여러 곳에 흩어져 있으면 캐시 효율이 낮아질 수 있다.

## 실무적 의미
NumPy, 벡터화, 행렬 연산, 미니배치 학습은 모두 메모리 배치의 영향을 받는다. 알고리즘의 이론적 시간 복잡도가 같더라도 데이터가 메모리에 어떻게 놓이고 접근되는지에 따라 실제 실행 시간은 크게 달라진다.

성능 최적화에서는 계산 횟수만 줄이는 것이 아니라 데이터 접근 패턴도 봐야 한다. 연속 배열, 배치 크기, 자료형, 반복문 순서가 캐시 효율에 영향을 준다.

## 주의할 점
코드가 추상적으로 깔끔하다고 항상 빠른 것은 아니다. 작은 데이터에서는 차이가 미미하지만, 대규모 배열과 반복 계산에서는 지역성 차이가 병목이 될 수 있다.

다만 성능 최적화는 실제 병목을 측정한 뒤에 해야 한다. 먼저 읽기 쉬운 구조를 유지하고, 문제가 확인된 부분에서 데이터 구조와 접근 패턴을 조정하는 편이 좋다.
