# scikit-learn

## 핵심 정의

scikit-learn은 파이썬에서 전통적인 머신러닝 모델을 만들고 평가하기 위한 표준 라이브러리다. 분류, 회귀, 군집화, 차원 축소, 전처리, 모델 선택 기능을 일관된 인터페이스로 제공한다.

이 라이브러리의 가치는 알고리즘의 종류뿐 아니라 작업 방식의 표준화에 있다. 서로 다른 모델도 `fit`, `predict`, `score`, `transform` 같은 공통 메서드를 따르기 때문에 모델을 바꿔 실험하고 비교하기 쉽다.

## 작동 방식

scikit-learn은 추정기(estimator) 중심 설계를 사용한다. 모델은 `fit()`으로 데이터를 학습하고, `predict()`로 새 데이터의 결과를 예측하며, 전처리 도구는 `transform()`으로 데이터를 변환한다.

파이프라인을 사용하면 전처리와 모델링 단계를 하나의 흐름으로 묶을 수 있다. 이렇게 하면 훈련 데이터와 테스트 데이터에 같은 변환을 적용하기 쉽고, 교차 검증 과정에서 데이터 누설을 줄일 수 있다.

## 실무적 의미

scikit-learn은 머신러닝 프로젝트의 기준 모델을 빠르게 만들 때 강하다. 로지스틱 회귀, k-최근접 이웃, 랜덤 포레스트, 서포트 벡터 머신, 주성분분석 같은 모델을 같은 방식으로 호출하고 비교할 수 있다.

교육과 실무 양쪽에서 자주 쓰이는 이유는 전체 워크플로우가 깔끔하기 때문이다. 데이터 분리, 교차 검증, 하이퍼파라미터 탐색, 모델 평가를 안정적으로 반복할 수 있다.

## 주의할 점

scikit-learn은 주로 CPU 기반의 정형 데이터 머신러닝에 초점을 둔다. 대규모 딥러닝이나 GPU 중심 학습은 PyTorch, TensorFlow 같은 별도 프레임워크가 더 적합한 경우가 많다.

또한 편리한 인터페이스가 데이터 누설을 자동으로 막아 주지는 않는다. 전처리기를 전체 데이터에 먼저 맞춘 뒤 데이터를 나누면 검증 성능이 과장될 수 있다. 파이프라인과 교차 검증을 올바르게 써야 한다.
