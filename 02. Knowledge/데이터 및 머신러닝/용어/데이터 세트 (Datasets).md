# 데이터 세트 (Datasets)

## 핵심 정의
데이터 세트는 분석이나 모델 학습에 사용하기 위해 일정한 목적과 구조로 모아 놓은 데이터 묶음이다. 표, 이미지, 텍스트, 로그, 센서 값, 음성처럼 다양한 형태를 가질 수 있다.

머신러닝에서 데이터 세트는 모델의 학습 재료다. 모델의 성능은 알고리즘뿐 아니라 데이터 세트의 품질, 규모, 대표성, 라벨 정확도에 크게 의존한다.

## 작동 방식
데이터 세트는 보통 훈련, 검증, 테스트 용도로 나뉜다. 훈련 데이터는 모델이 패턴을 학습하는 데 쓰이고, 검증 데이터는 모델 선택과 튜닝에 쓰이며, 테스트 데이터는 최종 성능을 확인하는 데 쓰인다.

데이터 세트는 CSV, JSON, Parquet, 이미지 폴더, 데이터베이스 테이블 등 여러 형식으로 저장될 수 있다. 중요한 것은 파일 형식보다 각 열과 행이 무엇을 의미하는지, 수집 과정에 어떤 제약이 있었는지, 어떤 목적에 맞게 사용할 수 있는지다.

## 실무적 의미
좋은 데이터 세트는 모델 개발 속도와 결과의 신뢰도를 높인다. 컬럼 정의, 라벨 기준, 결측치 처리 방식, 수집 기간, 표본 기준이 명확하면 분석가는 모델링보다 문제 이해에 더 많은 에너지를 쓸 수 있다.

반대로 데이터 세트의 맥락이 불명확하면 모델 성능이 좋아 보여도 실제 적용에서 실패할 수 있다. 특히 운영 환경과 데이터 세트의 분포가 다르면 모델은 학습 때 본 패턴을 그대로 적용하지 못한다.

## 주의할 점
데이터 세트는 중립적인 원재료가 아니다. 수집 방식, 측정 도구, 라벨링 기준, 누락된 사례, 표본 편향이 모두 결과에 영향을 준다.

또한 훈련 데이터와 평가 데이터가 섞이면 성능이 실제보다 높게 보이는 데이터 누설이 발생한다. 데이터 분할은 모델링 전에 신중하게 설계해야 하며, 전처리 과정에서도 평가 데이터의 정보가 훈련에 들어가지 않게 해야 한다.
