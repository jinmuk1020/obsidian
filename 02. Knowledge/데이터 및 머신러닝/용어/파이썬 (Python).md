# 파이썬 (Python)

## 핵심 정의
파이썬은 간결한 문법과 풍부한 라이브러리 생태계를 가진 범용 프로그래밍 언어다. 데이터 분석과 머신러닝에서는 데이터를 불러오고, 정리하고, 모델을 만들고, 결과를 시각화하는 과정을 연결하는 작업 언어로 널리 쓰인다.

파이썬의 강점은 언어 자체의 실행 속도보다 개발 속도와 생태계에 있다. NumPy, Pandas, scikit-learn 같은 라이브러리가 내부적으로 최적화된 계산을 제공해 분석 생산성을 높인다.

## 작동 방식
파이썬은 인터프리터 방식으로 코드를 실행하며, 객체 지향과 함수형 스타일을 모두 지원한다. 데이터 과학에서는 노트북 환경에서 작은 단위로 코드를 실행하며 데이터를 탐색하고 모델을 반복 개선하는 방식이 흔하다.

무거운 수치 계산은 순수 파이썬 반복문보다 NumPy 배열, Pandas 연산, scikit-learn 모델처럼 최적화된 라이브러리를 통해 처리하는 것이 일반적이다.

## 실무적 의미
파이썬은 데이터 분석 워크플로 전체를 하나의 언어로 묶어 준다. 데이터 수집 스크립트, 전처리, 통계 분석, 머신러닝 모델링, API 연동, 자동화까지 같은 환경에서 이어갈 수 있다.

커뮤니티와 패키지 생태계가 크기 때문에 새로운 분석 기법이나 모델을 실험하기 쉽다. 실무에서는 빠르게 검증하고 필요한 부분만 운영 코드로 정리하는 방식이 자주 쓰인다.

## 주의할 점
파이썬의 편리함은 성능 문제를 숨길 수 있다. 작은 데이터에서는 잘 돌아가던 코드가 대용량 데이터에서는 느려질 수 있으므로 벡터화, 메모리 사용량, 병목을 확인해야 한다.

또한 노트북 기반 작업은 실행 순서 의존성이 생기기 쉽다. 중요한 분석은 재실행 가능한 스크립트나 파이프라인으로 정리해야 한다.
