# 변수 (Variables)

## 핵심 정의
변수는 값이 달라질 수 있는 속성이나 이름 붙은 값이다. 데이터 분석에서는 관측 대상의 특성을 나타내고, 프로그래밍과 시스템 설계에서는 상태나 입력값을 참조하는 이름으로 쓰인다.

중요한 것은 이름 자체가 아니라 그 값이 무엇을 대표하고, 어떤 맥락에서 해석되는가이다. 같은 값도 분석 목적에 따라 입력 변수, 목표 변수, 상태 변수, 통제 변수처럼 다른 역할을 맡을 수 있다.

## 작동 방식
데이터 분석에서 변수는 모델이 현상을 설명하거나 예측하는 기본 단위가 된다. 예를 들어 사용 시간, 구매 횟수, 세션 길이, 반응 시간 같은 값은 서로 다른 변수로 기록되고, 변수 사이의 관계를 통해 패턴을 찾는다.

머신러닝에서는 변수가 모델에 들어가는 입력 특성으로 정리된다. 이때 원자료를 그대로 쓰기보다 분석 목적에 맞게 정리하고 변환하는 과정이 필요하며, 이 작업은 [[특성 공학]]과 연결된다.

## 실무적 의미
변수 정의가 명확해야 분석과 구현이 안정된다. 같은 이름의 변수가 서로 다른 의미로 쓰이거나, 같은 의미의 값이 여러 이름으로 흩어지면 데이터 해석과 시스템 유지보수가 어려워진다.

또한 변수는 측정 가능한 형태로 정의되어야 한다. 막연한 개념을 그대로 변수로 삼기보다 실제로 기록할 수 있는 관측값, 상태값, 분류값으로 바꾸어야 한다. 이 지점은 [[측정 기준과 측정 항목 (Dimension and Metric)]]과 연결된다.

## 주의할 점
변수는 현실 자체가 아니라 현실을 특정 관점에서 잘라낸 표현이다. 어떤 변수를 선택했는지에 따라 보이는 문제가 달라지고, 선택하지 않은 변수는 분석 밖으로 사라진다.

또한 변수 사이의 관계가 곧 원인을 뜻하지는 않는다. [[상관관계(Correlation)의 유형]]은 패턴을 발견하게 해주지만, 인과를 주장하려면 별도의 설계와 검증이 필요하다.
