# Pandas

## 핵심 정의

Pandas는 파이썬에서 표 형태의 데이터를 읽고, 정리하고, 분석하기 위한 라이브러리다. 행과 열로 구성된 `DataFrame`을 중심으로 작동하며, CSV, 엑셀, 데이터베이스에서 가져온 현실의 데이터를 분석 가능한 형태로 다루게 해 준다.

Pandas는 수치 계산 라이브러리인 [[NumPy와 벡터화 (Vectorization)]] 위에서 데이터 분석가에게 익숙한 테이블 조작 방식을 제공한다.

## 작동 방식

Pandas의 핵심 구조는 `DataFrame`과 `Series`다. `DataFrame`은 행과 열을 가진 2차원 테이블이고, `Series`는 인덱스를 가진 1차원 데이터다.

필터링, 그룹화, 병합, 정렬, 결측치 처리, 타입 변환, 집계 같은 전처리 작업을 함수 형태로 제공한다. 이 때문에 탐색적 데이터 분석과 모델 입력 준비 과정에서 자주 쓰인다.

## 실무적 의미

대부분의 데이터 분석 프로젝트는 모델링보다 데이터 정리에 더 많은 시간이 든다. Pandas는 원천 데이터를 읽고, 이상값과 결측값을 확인하고, 분석 단위에 맞게 집계하고, 모델 입력 형태로 바꾸는 작업을 담당한다.

노트북 환경에서도 Pandas는 분석의 공용 언어처럼 쓰인다. 데이터를 눈으로 확인하고 가설을 세우며, 이후 [[scikit-learn]] 모델에 넣을 수 있는 형태로 변환하는 연결 역할을 한다.

## 주의할 점

Pandas는 기본적으로 메모리 안에서 데이터를 처리한다. 데이터가 커질수록 속도와 메모리 문제가 생길 수 있으므로 필요한 열만 읽기, 타입 최적화, 청크 처리, 데이터베이스 활용을 고려해야 한다.

또한 체인 인덱싱과 묵시적 복사는 예상과 다른 결과를 만들 수 있다. 중요한 전처리에서는 원본과 변환본을 명확히 구분하고, 변환 과정을 재현 가능하게 기록해야 한다.

- 데이터 전처리 | Pandas가 가장 자주 쓰이는 작업 영역이다.
- 탐색적 데이터 분석 | 데이터를 이해하고 가설을 세우는 초기 분석 단계다.
