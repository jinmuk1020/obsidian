# 캐시 미스 (Cache Miss)

## 핵심 정의
캐시 미스는 CPU가 필요한 데이터를 캐시에서 찾지 못해 더 느린 메인 메모리에서 가져와야 하는 상황이다. 캐시 미스가 많아지면 CPU가 계산할 준비가 되어 있어도 데이터가 도착할 때까지 기다리게 된다.

고성능 데이터 처리에서 캐시 미스는 눈에 잘 보이지 않는 중요한 병목이다. 계산량이 같아도 메모리 접근 패턴에 따라 실행 속도는 크게 달라질 수 있다.

## 작동 방식
CPU 캐시는 최근 접근한 데이터와 그 주변 데이터를 저장한다. 필요한 데이터가 캐시에 있으면 캐시 히트가 발생해 빠르게 처리된다. 없으면 캐시 미스가 발생하고 메인 메모리 접근이 필요하다.

데이터가 연속적으로 배치되어 있고 순서대로 접근하면 캐시 효율이 높다. 반대로 데이터가 메모리 여러 곳에 흩어져 있거나 접근 순서가 불규칙하면 캐시 미스가 늘어난다.

## 실무적 의미
데이터 분석과 머신러닝에서는 큰 배열과 반복 연산이 많다. NumPy 배열, 행렬 연산, 배치 처리에서 데이터가 캐시 친화적으로 놓이면 같은 알고리즘도 훨씬 빠르게 실행될 수 있다.

성능 최적화에서는 연산 횟수만 줄이는 것이 아니라 데이터가 메모리에 어떻게 배치되고 접근되는지 함께 봐야 한다.

## 주의할 점
캐시 미스 문제는 단순히 CPU가 느리다는 문제가 아니다. 데이터 구조와 접근 순서가 원인인 경우가 많다.

다만 캐시 수준의 최적화는 실제 병목을 측정한 뒤에 해야 한다. 먼저 전체 파이프라인에서 어디가 느린지 확인하고, 필요한 부분에서 메모리 접근 패턴을 조정하는 것이 좋다.
