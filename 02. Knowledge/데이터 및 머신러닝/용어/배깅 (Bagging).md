# 배깅 (Bagging)

## 핵심 정의
배깅은 Bootstrap Aggregating의 줄임말로, 원본 데이터에서 복원 추출한 여러 표본으로 여러 모델을 학습시키고 그 예측을 평균이나 투표로 결합하는 앙상블 학습 방법이다. 단일 모델보다 예측을 더 안정적으로 만들기 위해 사용된다.

배깅의 핵심 목적은 모델의 분산을 줄이는 것이다. 데이터가 조금 달라질 때 예측이 크게 흔들리는 모델을 여러 개 만들고 결합하면, 개별 모델의 불안정성이 평균화된다.

## 작동 방식
먼저 원본 데이터에서 중복을 허용해 여러 개의 부트스트랩 표본을 만든다. 각 표본으로 별도의 모델을 학습시킨 뒤, 회귀에서는 예측값을 평균내고 분류에서는 다수결로 최종 예측을 정한다.

대표적인 배깅 모델은 랜덤 포레스트다. 랜덤 포레스트는 부트스트랩 표본을 사용할 뿐 아니라 각 분기에서 일부 특성만 무작위로 고려해 나무들 사이의 다양성을 더 높인다.

## 실무적 의미
배깅은 과적합되기 쉬운 불안정한 모델에 특히 유용하다. 의사결정나무처럼 데이터 변화에 민감한 모델은 배깅을 통해 훨씬 안정적인 예측을 만들 수 있다.

실무에서는 모델 하나의 해석보다 예측 안정성과 성능이 더 중요할 때 배깅 계열 모델을 고려한다. 표 형태 데이터에서 빠르게 강한 기준 모델을 만들 때도 유용하다.

## 주의할 점
배깅은 모델의 분산을 줄이는 데 강하지만, 편향이 큰 모델을 근본적으로 고치지는 못한다. 기본 모델이 지나치게 단순해 중요한 패턴을 놓친다면 여러 개를 평균해도 한계가 있다.

또한 여러 모델을 학습하므로 계산 비용과 메모리 사용량이 늘어난다. 성능 개선 폭과 운영 비용의 균형을 함께 봐야 한다.
