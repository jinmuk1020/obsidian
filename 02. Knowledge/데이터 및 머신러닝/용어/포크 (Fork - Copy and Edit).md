# 포크 (Fork - Copy and Edit)

## 핵심 정의
포크는 기존 프로젝트, 코드, 노트북, 데이터 분석 작업을 복사해 독립적으로 수정할 수 있는 새 작업본을 만드는 행위다. 원본을 보존하면서 자신의 실험이나 개선을 진행할 수 있게 해준다.

Kaggle이나 GitHub 같은 협업 환경에서 포크는 학습과 재사용의 기본 방식이다. 다른 사람의 분석을 출발점으로 삼되, 변경 사항은 별도의 사본에서 관리한다.

## 작동 방식
포크를 만들면 원본의 파일과 설정이 복사된다. 사용자는 복사본에서 코드를 수정하고, 데이터를 바꾸고, 모델을 실험한다. 원본과 달라진 부분은 비교하거나 다시 제안할 수 있다.

노트북 환경에서는 공개 노트북을 복사해 자신의 데이터와 아이디어를 적용하는 식으로 쓰인다. 이때 원본의 의도와 라이선스, 데이터 사용 조건을 확인해야 한다.

## 실무적 의미
포크는 재현성과 협업을 높인다. 원본을 직접 망가뜨리지 않고 실험할 수 있고, 성공한 변경만 나중에 병합하거나 공유할 수 있다.

데이터 분석 학습에서도 포크는 중요하다. 좋은 예제 노트북을 복사해 실행해 보고, 일부만 바꾸며 결과가 어떻게 달라지는지 확인할 수 있다.

## 주의할 점
포크한 작업이 원본과 어떤 점에서 달라졌는지 기록하지 않으면 나중에 재현과 협업이 어려워진다. 변경 목적과 실험 결과를 함께 남겨야 한다.

또한 원본 데이터나 코드의 라이선스와 공개 범위를 확인해야 한다. 사본을 만들 수 있다고 해서 모든 내용을 자유롭게 재배포할 수 있는 것은 아니다.
