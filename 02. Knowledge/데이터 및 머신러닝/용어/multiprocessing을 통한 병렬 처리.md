# multiprocessing을 통한 병렬 처리

## 핵심 정의

`multiprocessing`은 파이썬에서 여러 프로세스를 생성해 CPU 중심 작업을 병렬로 실행하게 해 주는 표준 라이브러리다. 각 프로세스는 독립된 메모리 공간과 독립된 인터프리터를 가지므로, CPython의 전역 인터프리터 락 제약을 피할 수 있다.

스레드가 하나의 프로세스 안에서 실행 흐름을 나누는 방식이라면, multiprocessing은 여러 프로세스로 작업을 나누어 여러 CPU 코어를 활용한다.

## 작동 방식

작업을 여러 조각으로 나누고, 각 조각을 별도 프로세스에 배분한다. `Process`, `Pool`, `Queue`, `Pipe`, 공유 메모리 같은 도구를 사용해 작업 실행과 결과 수집을 관리할 수 있다.

`Pool`은 여러 작업을 워커 프로세스에 나누어 실행하는 데 자주 쓰인다. 각 워커는 독립적으로 계산하고 결과를 부모 프로세스에 돌려준다.

## 실무적 의미

대규모 시뮬레이션, 반복 계산, 파일별 전처리, 몬테카를로 실험처럼 서로 독립적인 CPU 작업은 multiprocessing의 좋은 대상이다. 단일 코어 실행의 한계를 넘어 여러 코어를 활용할 수 있다.

다만 프로세스 간 데이터 전달에는 직렬화와 복사 비용이 든다. 작은 작업을 너무 잘게 나누면 병렬화 이익보다 통신 비용이 커질 수 있다.

## 주의할 점

multiprocessing은 모든 작업을 빠르게 만들지 않는다. I/O 중심 작업은 비동기 처리나 스레드가 더 적합할 수 있고, 큰 데이터를 워커마다 복사하면 메모리 사용량이 급격히 늘어난다.

Windows 환경에서는 프로세스 시작 방식 때문에 `if __name__ == "__main__":` 보호 구문이 중요하다. 이를 빼면 자식 프로세스가 반복 생성되는 문제가 생길 수 있다.
