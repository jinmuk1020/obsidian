# 데이터베이스

## 핵심 정의
데이터베이스는 여러 사용자가 공유하고 활용할 수 있도록 데이터를 구조적으로 저장하고 관리하는 시스템이다. 단순한 파일 묶음이 아니라 데이터의 무결성, 권한, 조회, 수정, 동시성, 백업을 함께 다루는 운영 기반이다.

분석과 머신러닝에서 데이터베이스는 원천 데이터의 저장소 역할을 한다. 잘 설계된 데이터베이스가 있어야 분석가는 필요한 데이터를 안정적으로 추출하고, 모델 학습과 의사결정에 활용할 수 있다.

## 작동 방식
데이터베이스 관리 시스템은 데이터 정의, 삽입, 수정, 삭제, 조회를 위한 기능을 제공한다. 관계형 데이터베이스는 데이터를 테이블로 구성하고 SQL로 질의하며, 비관계형 데이터베이스는 문서, 키-값, 그래프 등 다양한 구조를 지원한다.

조직의 규모와 목적에 따라 운영 데이터베이스, 데이터 웨어하우스, 데이터 마트, 데이터 레이크처럼 다른 저장 구조가 쓰인다. 운영 시스템은 거래와 상태 변경에 강하고, 분석 시스템은 대량 조회와 집계에 맞춰 설계된다.

## 실무적 의미
데이터베이스는 분석의 출발점이다. 데이터가 어떤 테이블에 있고, 어떤 키로 연결되며, 어떤 기준으로 업데이트되는지 이해하지 못하면 정확한 분석을 하기 어렵다.

머신러닝 프로젝트에서도 데이터베이스 이해는 중요하다. 잘못된 조인, 중복된 레코드, 시점이 맞지 않는 데이터 추출은 모델 성능보다 더 근본적인 오류를 만든다.

## 주의할 점
데이터베이스는 저장소이면서 동시에 설계의 결과물이다. 권한, 인덱스, 정규화 수준, 스키마 변경 이력, 데이터 품질 규칙이 모두 분석 결과에 영향을 준다.

또한 운영 데이터베이스를 분석 목적으로 무리하게 조회하면 서비스 성능에 영향을 줄 수 있다. 실무에서는 분석용 복제본이나 데이터 웨어하우스를 통해 운영과 분석의 부하를 분리하는 편이 좋다.
