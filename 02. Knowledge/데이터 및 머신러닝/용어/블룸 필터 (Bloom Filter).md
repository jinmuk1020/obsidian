# 블룸 필터 (Bloom Filter)

## 핵심 정의
블룸 필터는 어떤 원소가 집합에 속하는지 빠르게 확인하기 위한 공간 효율적인 확률적 자료구조다. 정확한 전체 데이터를 저장하지 않고도 “없다”는 판단을 빠르게 내릴 수 있다는 점이 핵심이다.

블룸 필터는 거짓 긍정을 허용한다. 즉 실제로는 없는 원소를 있을 수 있다고 말할 수는 있지만, 실제로 있는 원소를 없다고 말하지는 않는다. 이 성질 때문에 대규모 시스템에서 불필요한 조회를 줄이는 데 쓰인다.

## 작동 방식
블룸 필터는 비트 배열과 여러 해시 함수를 사용한다. 원소를 추가할 때 여러 해시 함수가 가리키는 위치의 비트를 1로 바꾼다. 나중에 어떤 원소를 검사할 때 같은 위치들이 모두 1이면 “있을 수 있음”이라고 판단하고, 하나라도 0이면 “확실히 없음”이라고 판단한다.

여러 원소가 같은 비트를 공유할 수 있기 때문에 거짓 긍정이 생긴다. 비트 배열이 작거나 저장한 원소가 많을수록 충돌이 늘어나고 거짓 긍정률이 높아진다.

## 실무적 의미
블룸 필터는 비싼 조회를 하기 전에 빠른 사전 검사를 할 때 유용하다. 캐시, 데이터베이스, 분산 저장소, 중복 검사, 악성 URL 검사처럼 데이터가 크고 조회 비용이 높은 시스템에서 사용된다.

예를 들어 어떤 키가 데이터베이스에 없다는 것을 블룸 필터가 빠르게 알려주면, 실제 데이터베이스 조회를 생략할 수 있다. 이때 약간의 거짓 긍정은 감수하되 전체 시스템 처리량을 높이는 방식이다.

## 주의할 점
기본 블룸 필터는 삭제가 어렵다. 여러 원소가 같은 비트를 공유하기 때문에 한 원소를 지우려고 비트를 0으로 바꾸면 다른 원소의 존재 정보까지 망가질 수 있다.

또한 블룸 필터는 정확한 저장소가 아니다. “있을 수 있음”은 확정이 아니므로, 중요한 판단에서는 실제 저장소 조회나 추가 검증이 필요하다.
