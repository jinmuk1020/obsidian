# 확률적 자료구조 (Probabilistic Data Structures)

- Source ID: `3f215fbd-ca74-4d92-9e97-6f794cce83c1`

## 핵심 설명

확률적 자료구조는 약간의 정확도를 희생하는 대신 메모리 사용량을 극적으로 줄이는 고도의 데이터 압축 전략입니다. 하이퍼로그로그(HyperLogLog)는 수십억 개의 고유 원소 개수를 단 몇 KB로 추정하며, 블룸 필터(Bloom Filter)는 원소의 포함 여부를 비트 배열만으로 빠르게 확인합니다. 이러한 구조는 데이터 전체를 RAM에 저장할 수 없는 거대 규모의 스트리밍 데이터 분석에서 성능과 공간의 완벽한 트레이드오프를 제공합니다. [24-27]

## 핵심 포인트

- 정확도와 메모리 사용량 사이의 유연한 조절(Trade-off)
- 데이터의 본질적인 정보만 보존하는 손실 압축 형태의 저장
- 거대 데이터셋에서 유일 원소 카운팅 및 포함 여부 확인에 최적화

## 중요성

한정된 하드웨어 자원 내에서 물리적으로 불가능해 보이는 대규모 데이터 분석 과제를 실현 가능하게 만듭니다.
