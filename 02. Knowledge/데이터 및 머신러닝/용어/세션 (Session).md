# 세션 (Session)

## 핵심 정의
세션은 한 사용자가 일정 시간 동안 사이트나 앱 안에서 이어 간 상호작용의 묶음이다. 페이지 조회, 이벤트, 전환 같은 개별 행동은 각각의 로그로 남지만, 세션은 그 행동들이 하나의 방문 맥락 안에서 어떻게 이어졌는지를 보여준다.

세션은 사용자와 다르다. 사용자는 사람 또는 식별자를 기준으로 한 단위이고, 세션은 그 사용자가 특정 시점에 시작해서 일정 시간 동안 이어 간 방문 단위다. 그래서 같은 사용자가 하루에 여러 번 방문하면 여러 세션이 생길 수 있다.

## 작동 방식
분석 도구는 보통 첫 상호작용이 발생하면 세션을 시작하고, 일정 시간 동안 추가 상호작용이 없으면 세션을 종료한다. 구글 애널리틱스에서는 전통적으로 30분 비활동 기준이 세션 구분의 기본값으로 쓰였다.

세션 안에는 유입 경로, 조회한 화면, 클릭 이벤트, 체류 시간, 이탈 여부, 전환 여부 같은 정보가 함께 묶인다. 따라서 세션은 단순 방문 횟수가 아니라 사용자가 어떤 경로로 들어와 어디에서 멈추거나 전환했는지를 읽는 분석 단위다.

## 실무적 의미
세션은 마케팅과 제품 분석에서 방문 품질을 판단하는 기본 단위다. 세션 수만 늘었는데 전환이 늘지 않는다면 유입의 양은 증가했지만 방문 맥락의 질은 낮을 수 있다. 반대로 세션 수는 적어도 세션당 전환율이 높다면 더 좁고 명확한 사용자를 끌어오고 있을 가능성이 있다.

게임이나 서비스 분석에서도 세션은 플레이 루프와 사용자 몰입을 보는 단위가 된다. 한 세션 안에서 사용자가 어떤 행동을 반복하고 어디에서 끊기는지를 보면 [[퍼널]]이나 [[이탈률 (Bounce Rate)]]을 더 구체적으로 해석할 수 있다.

## 주의할 점
세션 수는 사용자 수가 아니다. 한 명의 충성 사용자가 여러 번 접속하면 세션은 크게 늘지만 실제 사용자 저변이 늘어난 것은 아닐 수 있다.

또한 세션 기준은 도구 설정에 따라 달라진다. 세션 타임아웃, 캠페인 변경, 날짜 경계 같은 규칙이 바뀌면 같은 행동 데이터도 다른 세션 수로 집계될 수 있으므로, 기간 비교를 할 때는 측정 기준을 함께 확인해야 한다.

## 연결된 생각
- 사용자 | 세션과 사용자 단위를 구분해야 방문 품질과 사용자 규모를 혼동하지 않는다.
- [[이벤트 (Event)]] | 세션은 여러 이벤트를 하나의 방문 맥락으로 묶는다.
- [[전환 (Conversion)]] | 세션 안에서 목표 행동이 일어났는지가 성과 분석의 핵심이다.
- [[이탈률 (Bounce Rate)]] | 세션이 충분한 상호작용 없이 끝난 비율을 해석하는 데 필요하다.
