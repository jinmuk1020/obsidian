# 콘텐츠 관계도

## 핵심 정의

콘텐츠 관계도는 게임의 시스템, 자원, 플레이 요소, 보상, 진행 구조가 서로 어떻게 연결되는지 시각화한 도표다. 개별 콘텐츠 목록이 아니라, 콘텐츠가 어떤 원인과 결과의 흐름 속에서 작동하는지 보여준다.

핵심 루프, 전투, 성장, 제작, 퀘스트, 경제, 보상 같은 요소가 서로 어떻게 이어지는지 한눈에 확인하게 해준다.

## 작동 방식

콘텐츠 관계도는 중심 루프를 기준으로 주요 요소를 연결한다. 예를 들어 전투는 경험치와 재료를 만들고, 경험치는 성장으로 이어지며, 성장과 제작은 더 높은 난이도의 전투를 가능하게 한다.

이런 도표를 통해 어떤 플레이가 다른 플레이로 이어지는지, 자원이 어디서 생기고 어디서 소비되는지, 보상이 장기 동기를 만드는지 확인할 수 있다.

## 설계에서의 의미

콘텐츠 관계도는 팀이 게임의 전체 구조를 공유하게 한다. 부분 시스템이 잘 만들어졌더라도 서로 순환하지 않으면 장기 플레이 동기가 약해진다.

또한 관계도는 빈 연결을 찾게 해준다. 어떤 콘텐츠가 보상이나 성장과 연결되지 않거나, 핵심 루프와 따로 놀면 우선순위를 다시 검토할 수 있다.

## 주의할 점

한 장에 모든 조건과 예외를 넣으면 읽을 수 없어진다. 큰 흐름과 세부 규칙은 분리해서 단계별로 표현해야 한다.

콘텐츠 관계도는 실제 수치표가 아니라 설계 커뮤니케이션 도구다. 세부 수치는 데이터 테이블에서 관리하고, 관계도는 구조와 흐름을 보여주는 데 집중하는 것이 좋다.
