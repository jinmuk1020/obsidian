# 가치 기반 의사결정 (Value-based Decisions)

## 핵심 정의
> 가치 기반 의사결정은 효율 계산만이 아니라 무엇을 중요하게 여기는가를 기준으로 선택을 설계하거나 판단하는 방식이다.

* **플레이어 관점:** 선택이 캐릭터의 신념, 관계, 장기 목표와 연결된다.
* **개발 관점:** 게임의 핵심 가치와 목표 경험을 기준으로 기능과 콘텐츠를 선택한다.
* **핵심 효과:** 선택에 의미와 정체성을 부여한다.

## 작동 방식
게임의 선택은 비용과 보상만으로 결정되지 않는다. 플레이어는 더 강한 보상보다 공정함, 역할 몰입, 캐릭터 관계, 도덕적 기준, 장기적 신뢰를 선택할 수 있다. 가치 기반 의사결정은 이런 층위를 의도적으로 설계한다.

개발 과정에서도 같은 원리가 작동한다. 빠른 출시, 완성도, 수익성, 커뮤니티 신뢰, 접근성 같은 가치가 충돌할 때 무엇을 우선할지 명확해야 한다.

## 설계적 의미
가치 기반 선택은 플레이어 선택을 깊게 만든다. “무엇이 더 강한가”가 아니라 “내가 어떤 플레이어인가”를 묻게 하기 때문이다. 선택의 결과가 세계, 캐릭터, 관계, 시스템에 반영되면 의미가 커진다.

운영형 게임에서는 개발팀의 가치 기준도 중요하다. 밸런스 패치, 과금 정책, 이벤트 보상, 커뮤니티 대응은 게임이 어떤 가치를 우선하는지 드러낸다.

## 주의할 점
가치가 불명확하면 선택은 임시방편이나 취향으로 흐른다. 플레이어 선택에서도 가치 충돌만 강요하고 결과를 보여주지 않으면 의미가 약해진다.
