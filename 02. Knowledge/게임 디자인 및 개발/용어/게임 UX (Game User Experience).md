# 게임 UX (Game User Experience)

## 핵심 정의

게임 UX는 플레이어가 게임을 배우고, 조작하고, 해석하고, 감정적으로 받아들이는 전체 경험을 말한다. 일반적인 UX가 사용자의 목표 달성과 효율을 중시한다면, 게임 UX는 여기에 재미, 도전, 몰입, 실패, 긴장, 보상, 숙련의 감각까지 포함한다.

게임 UX는 UI만의 문제가 아니다. 버튼 배치, 메뉴 구조, 튜토리얼, 피드백, 난이도 곡선, 카메라, 조작감, 사운드, 보상, 레벨 구조, 내러티브 전달 방식이 모두 플레이어 경험을 만든다.

## 작동 방식

플레이어는 게임을 하면서 계속 질문한다. 지금 무엇을 해야 하는가, 내가 무엇을 할 수 있는가, 방금 일어난 일이 왜 일어났는가, 다음에 더 잘하려면 무엇을 바꿔야 하는가. 게임 UX는 이 질문들에 대한 답을 명확하고 자연스럽게 제공해야 한다.

좋은 UX는 플레이어가 게임의 규칙을 스스로 발견하고 익히도록 돕는다. 필요한 정보는 적절한 순간에 보이고, 피드백은 행동과 결과를 연결하며, 실패는 다음 시도를 위한 단서가 된다. 나쁜 UX는 플레이어가 게임과 싸우는 것이 아니라 인터페이스와 싸우게 만든다.

## 설계적 의미

게임 UX의 핵심은 통제감과 이해 가능성이다. 플레이어는 모든 것을 통제할 수 없어도, 적어도 자신의 입력과 결과 사이의 관계를 이해할 수 있어야 한다. [[게임 필 (Game Feel)]]은 조작과 반응의 감각적 층위를 담당하고, [[사용성 (Usability)]]은 정보와 조작의 명료성을 담당한다.

또한 게임 UX는 [[몰입 (Flow)]]과 연결된다. 플레이어의 실력과 도전이 적절히 맞고, 목표와 피드백이 분명할 때 플레이어는 방해 없이 경험에 빠져든다. UX가 거칠면 아무리 좋은 시스템도 플레이어에게 도달하지 못한다.

## 주의할 점

게임 UX를 불편함이 없는 상태로만 이해하면 안 된다. 게임은 때로 긴장, 불확실성, 압박, 실패를 의도적으로 사용한다. 중요한 것은 불편함이 설계된 도전인지, 설명 부족과 조작 문제에서 나온 마찰인지 구분하는 것이다.

의도된 어려움은 플레이어가 납득하고 극복할 수 있어야 한다. 의도되지 않은 어려움은 플레이어가 무엇을 잘못했는지도 알 수 없게 만든다.
