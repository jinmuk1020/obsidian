# Vector2 (좌표)

## 핵심 정의
Vector2는 2차원 공간에서 위치, 방향, 속도, 이동량을 표현하는 두 성분짜리 벡터다. 보통 `x`와 `y` 값을 가지며, 2D 게임의 좌표계와 움직임을 다룰 때 기본 단위로 쓰인다.

## 왜 중요한가
게임에서는 화면상의 위치, 캐릭터 이동 방향, 마우스 입력, 탄환 속도, UI 배치처럼 2차원 값이 계속 등장한다. Vector2는 이 값을 하나의 개념으로 묶어 계산할 수 있게 한다.

## 설계에서의 의미
Vector2는 단순한 좌표쌍이 아니라 연산 가능한 공간 정보다. 더하기로 이동량을 적용하고, 빼기로 방향을 구하며, 길이로 거리나 속도를 계산하고, 정규화로 방향만 남길 수 있다.

## 주의점
좌표계의 기준을 혼동하면 오류가 생긴다. 엔진마다 위쪽이 `+y`인지, 화면 좌표와 월드 좌표가 어떻게 다른지, 픽셀 단위와 월드 단위가 어떻게 변환되는지 확인해야 한다.
