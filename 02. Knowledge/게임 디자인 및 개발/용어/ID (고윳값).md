# ID (고윳값)

## 핵심 정의
ID는 데이터 테이블이나 시스템 안에서 특정 대상을 유일하게 식별하기 위해 부여하는 고유한 값이다. 이름이나 설명은 바뀔 수 있지만, ID는 시스템이 같은 대상을 안정적으로 참조하게 만든다.

## 왜 중요한가
게임 데이터에서는 아이템, 몬스터, 퀘스트, 스킬, 맵, 대화 노드 같은 요소가 각각 고유 ID를 가져야 한다. 시스템은 표시 이름보다 ID를 기준으로 데이터를 연결하고 저장한다.

## 설계에서의 의미
ID는 데이터 독립성을 만든다. 디자이너가 이름이나 수치를 바꿔도 코드와 저장 데이터는 같은 ID를 통해 대상을 찾을 수 있다. 그래서 ID는 사람이 읽기 쉬운 이름과 시스템이 참조하는 키를 분리하는 장치다.

## 주의점
ID가 중복되거나 변경되면 참조 오류가 발생한다. 특히 출시 후 저장 데이터, 로그, 밸런스 패치, 라이브 운영이 ID에 의존하므로 임의로 재사용하거나 삭제하면 위험하다.
