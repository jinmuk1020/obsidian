# 작업 기억 (Working Memory)

## 핵심 정의

작업 기억은 사람이 지금 당장 처리하고 조작할 수 있는 제한된 정보 공간이다. 플레이어는 화면의 모든 정보, 튜토리얼 문장, 적 패턴, UI 숫자, 목표를 동시에 유지하지 못한다.

게임 UX에서 작업 기억은 정보량과 학습 순서를 결정하는 중요한 제약이다.

## 게임에서의 의미

초보 플레이어에게 조작, 목표, 전투 규칙, UI, 아이템 설명을 한꺼번에 주면 작업 기억이 과부하된다. 그러면 플레이어는 핵심 행동을 배우기 전에 피로와 혼란을 느낀다.

좋은 디자인은 정보를 작은 단위로 나누고, 필요한 순간에 제시하며, 행동과 바로 연결한다. 플레이어가 직접 해보고 결과를 확인할 때 정보는 단기 기억에서 더 안정적인 이해로 넘어간다.

## 설계에서의 의미

작업 기억을 고려하면 튜토리얼, UI, 전투 피드백, 퀘스트 목표가 더 명확해진다. 중요한 정보는 한 번에 하나씩 강조하고, 반복과 환경 단서로 장기 기억을 돕는다.

플레이어가 지금 무엇을 기억해야 하는지, 무엇은 화면이나 환경이 대신 기억해 줄 수 있는지를 구분해야 한다. 미니맵, 퀘스트 저널, 아이콘, 색상, 사운드 피드백은 작업 기억 부담을 줄이는 외부 기억 장치가 될 수 있다.

## 주의할 점

정보를 줄이는 것이 항상 좋은 것은 아니다. 필요한 정보가 없으면 플레이어는 추측해야 하므로 오히려 부담이 커진다. 핵심은 적절한 시점과 우선순위다.

작업 기억의 한계는 플레이어마다 다르다. 초보자는 조작과 목표를 동시에 유지하기 어렵지만, 숙련자는 여러 정보를 하나의 패턴으로 묶어 처리한다.
