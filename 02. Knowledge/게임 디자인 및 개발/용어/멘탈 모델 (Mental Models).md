# 멘탈 모델 (Mental Models)

## 핵심 정의

멘탈 모델은 플레이어가 게임 시스템이 어떻게 작동한다고 머릿속에 구성한 설명이다. 플레이어는 코드를 알지 못해도 경험과 단서를 바탕으로 “이 버튼은 점프다”, “빨간 바닥은 위험하다”, “큰 적은 느리지만 강하다” 같은 내부 모델을 만든다.

좋은 게임은 플레이어가 실제 시스템과 가까운 멘탈 모델을 만들도록 돕는다. 나쁜 게임은 플레이어가 잘못된 가정을 하게 만들고, 그 결과를 불공정하게 느끼게 한다.

## 작동 방식

플레이어는 멘탈 모델을 바탕으로 예측하고 선택한다. 예측이 맞으면 시스템을 이해했다고 느끼고, 예측이 틀리면 다시 학습한다. 문제는 틀린 이유가 명확하지 않을 때다. 그러면 플레이어는 게임을 깊이 있는 시스템이 아니라 임의적인 규칙처럼 받아들인다.

멘탈 모델은 UI, 튜토리얼, 피드백, 레벨 디자인, 장르 관습을 통해 형성된다. 설명 텍스트보다 반복되는 경험과 일관된 신호가 더 강하게 작동한다.

## 설계적 의미

디자이너는 플레이어가 어떤 멘탈 모델을 만들기를 원하는지 의도해야 한다. 위험 색상, 사운드 신호, 버튼 배치, 적의 실루엣, 보상 연출은 모두 플레이어의 모델을 형성한다.

멘탈 모델이 안정되면 플레이어는 적은 설명으로도 복잡한 시스템을 이해한다. 반대로 모델이 계속 깨지면 플레이어는 매 상황을 새로 해석해야 하므로 피로해진다.

## 오류가 생기는 지점

시각적 단서와 실제 규칙이 다르면 멘탈 모델이 깨진다. 닿아 보이는 벽을 통과할 수 없거나, 같은 색의 아이템이 서로 다른 규칙을 가지거나, 공격 범위가 애매하면 플레이어는 시스템을 신뢰하지 못한다.

장르 관습도 강한 멘탈 모델을 만든다. 플레이어는 빨간색을 위험, 초록색을 회복, 금색을 희귀 보상으로 해석하는 경향이 있다. 관습을 깨려면 의도적인 학습 장치가 필요하다.
