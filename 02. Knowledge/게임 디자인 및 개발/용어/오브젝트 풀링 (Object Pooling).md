# 오브젝트 풀링 (Object Pooling)

오브젝트 풀링은 객체를 매번 생성하고 파괴하는 대신, 미리 만들어 둔 객체를 필요할 때 꺼내 쓰고 다시 반환하는 최적화 기법이다.

총알, 이펙트, 적 스폰, UI 팝업처럼 자주 생성되는 객체에 특히 유용하다.

## 작동 방식

처음에 일정 수의 객체를 미리 생성해 풀에 넣는다. 필요할 때 풀에서 비활성 객체를 가져와 위치와 상태를 초기화하고 활성화한다. 사용이 끝나면 파괴하지 않고 비활성화해 다시 풀로 돌려보낸다.

핵심은 재사용 전 상태 초기화다. 이전 위치, 이펙트, 이벤트 구독, 체력, 타이머가 남아 있으면 버그가 생긴다.

## 설계 의미

오브젝트 풀링은 성능 안정성을 높인다. 실시간 게임에서는 객체 생성과 가비지 컬렉션으로 인한 프레임 지연이 플레이 감각을 해칠 수 있다.

특히 모바일, 대규모 전투, 탄막, 파티클 효과처럼 객체 생성이 잦은 환경에서 체감 품질을 지키는 실무 기법이다.

## 주의할 점

풀이 너무 크면 메모리를 낭비하고, 너무 작으면 순간적으로 추가 생성이 발생해 장점이 줄어든다.

또한 풀링은 구조를 복잡하게 만든다. 객체의 생명주기를 명확히 관리하지 않으면 파괴보다 더 찾기 어려운 버그가 생길 수 있다.
