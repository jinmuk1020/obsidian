# FIFO (First In First Out)

## 핵심 정의
> FIFO는 먼저 들어온 항목을 먼저 처리하는 선입선출 원칙이다.

* **핵심 구조:** 큐(Queue)
* **처리 방식:** 뒤로 들어오고 앞으로 나간다.
* **게임 개발 맥락:** 입력, 이벤트, 작업 요청, 메시지, 경로 후보 처리처럼 순서가 중요한 시스템에 쓰인다.

## 작동 방식
FIFO는 항목이 들어온 순서를 보존한다. 새 항목은 큐의 뒤에 추가되고, 처리할 때는 큐의 앞에 있는 항목부터 꺼낸다. 이 구조는 처리 순서를 예측 가능하게 만들고 오래 기다린 항목이 먼저 처리되도록 한다.

게임에서는 입력 이벤트를 순서대로 처리하거나, 서버 메시지를 수신 순서대로 반영하거나, 작업 요청을 공정하게 분배할 때 사용된다. 절차적 생성이나 탐색 알고리즘에서도 후보를 발견 순서대로 다룰 때 큐가 쓰일 수 있다.

## 설계적 의미
FIFO는 단순하지만 안정적이다. 순서가 중요한 시스템에서는 디버깅과 예측 가능성을 높인다. 예를 들어 플레이어 입력이 들어온 순서와 다른 순서로 처리되면 조작감이 불안정해질 수 있다.

운영 시스템에서도 대기열은 공정성을 제공한다. 먼저 요청한 플레이어가 먼저 처리된다는 규칙은 이해하기 쉽다.

## 주의할 점
FIFO가 항상 최적은 아니다. 긴급한 작업이 뒤에 들어오면 앞의 작업이 끝날 때까지 기다려야 한다. 우선순위가 중요한 AI, 네트워크, 서버 매칭, 렌더링 작업에서는 우선순위 큐나 별도 스케줄링 전략이 필요할 수 있다.
