# L-시스템 (L-Systems)

## 핵심 정의
> L-시스템은 간단한 기호 문자열을 반복적으로 치환해 복잡한 구조를 생성하는 규칙 기반 생성 체계다.

* **기원:** 식물 성장과 같은 자연 구조 모델링
* **게임 활용:** 나무, 식생, 지형 패턴, 장식 구조, 유기적 형태 생성
* **핵심 원리:** 작은 규칙을 여러 번 적용하면 복잡한 결과가 나타난다.

## 작동 방식
L-시스템은 시작 문자열과 치환 규칙을 가진다. 예를 들어 `A`를 `AB`로, `B`를 `A`로 바꾸는 규칙을 반복하면 문자열이 점점 길고 복잡한 패턴으로 변한다.

이 문자열을 그래픽 명령으로 해석하면 선을 그리고, 회전하고, 가지를 치는 구조를 만들 수 있다. 같은 규칙이라도 각도, 길이, 반복 횟수, 무작위 변수를 바꾸면 다양한 형태가 나온다.

## 설계적 의미
L-시스템은 절차적 콘텐츠 생성의 중요한 원리를 보여준다. 디자이너는 결과물을 하나하나 그리는 대신 어떤 성장 규칙이 어떤 형태를 만드는지 조정한다.

이 방식은 자연스러운 변주를 만들기에 좋다. 숲의 나무들이 모두 달라 보이지만 같은 생장 규칙을 공유하게 만들 수 있다.

## 주의할 점
L-시스템의 결과가 보기 좋다고 해서 자동으로 좋은 게임플레이가 되지는 않는다. 생성된 구조가 플레이어 이동, 시야, 충돌, 성능, 목표 이해에 어떤 영향을 주는지 별도로 검증해야 한다.
