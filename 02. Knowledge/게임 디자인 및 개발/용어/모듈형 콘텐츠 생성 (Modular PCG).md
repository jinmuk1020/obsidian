# 모듈형 콘텐츠 생성 (Modular PCG)

## 핵심 정의

모듈형 콘텐츠 생성은 미리 설계한 방, 패턴, 오브젝트, 규칙 블록 같은 모듈을 조합해 새로운 콘텐츠를 만드는 [[절차적 콘텐츠 생성 (PCG)]] 방식이다. 완전히 자유롭게 생성하기보다, 사람이 검증한 조각을 다양한 방식으로 연결한다.

이 방식은 디자이너의 통제와 생성 다양성 사이의 균형을 잡는 데 유용하다.

## 작동 방식

디자이너는 먼저 모듈을 만든다. 방, 복도, 적 배치 세트, 퍼즐 조각, 지형 타일, 무기 부품, 퀘스트 단계 등이 모듈이 될 수 있다.

그다음 모듈 간 연결 규칙을 정의한다. 어떤 모듈이 어떤 모듈 뒤에 올 수 있는지, 난이도는 어떻게 상승하는지, 테마와 기능은 어떻게 충돌하지 않게 할지 정한다.

## 설계적 의미

모듈형 PCG는 생성 결과의 품질을 관리하기 쉽다. 각 모듈은 사람이 직접 검토할 수 있고, 생성기는 검증된 조각을 조합한다. 그래서 완전한 무작위 생성보다 안정적인 결과를 얻기 쉽다.

또한 팀 작업에 적합하다. 아티스트와 레벨 디자이너는 모듈을 만들고, 시스템 디자이너는 조합 규칙을 만든다. 생산과 규칙 설계를 분리할 수 있다.

## 한계

모듈이 적거나 연결 규칙이 단순하면 반복이 쉽게 드러난다. 같은 방이 방향만 바뀌어 반복되거나, 같은 이벤트 조합이 계속 나오면 생성 콘텐츠는 수작업 콘텐츠보다 더 기계적으로 느껴질 수 있다.

따라서 모듈형 PCG는 모듈 수보다 조합의 의미와 변주 방식을 설계해야 한다. 플레이어가 “다른 모듈”이 아니라 “다른 상황”을 경험해야 한다.
