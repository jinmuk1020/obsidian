# 키-값 쌍 (Key-Value Pair)

## 핵심 정의

키-값 쌍은 하나의 식별자와 그 식별자에 대응하는 값을 묶어 표현하는 데이터 구조다. 키는 값을 찾기 위한 이름이고, 값은 실제 저장된 데이터다. 예를 들어 `Name: Aria`, `Level: 12`, `Trust: 70`은 모두 키-값 쌍으로 볼 수 있다.

게임에서는 캐릭터 능력치, 아이템 속성, 설정 옵션, 로컬라이제이션 문자열, 퀘스트 플래그, 저장 데이터 등을 간단하게 표현하는 데 자주 쓰인다.

## 작동 방식

프로그램은 키를 이용해 필요한 값을 빠르게 찾는다. [[딕셔너리 (Dictionary, CSharp 자료구조)]]나 해시 맵은 키-값 쌍을 저장하고, 주어진 키에 대응하는 값을 조회하는 대표적인 자료구조다.

키는 보통 문자열, 숫자, [[ID (고윳값)]]처럼 고유하게 식별 가능한 값이다. 값은 숫자, 문자열, 불리언, 배열, 오브젝트 등 다양한 형태가 될 수 있다.

## 개발상의 의미

키-값 쌍은 기획 데이터와 코드 사이를 단순하게 연결한다. 예를 들어 `damage: 35`, `rarity: rare`, `isUnlocked: true`처럼 속성을 나누면 기획자가 데이터를 수정하기 쉽고, 코드도 일관된 방식으로 값을 읽을 수 있다.

내러티브 시스템에서도 키-값 쌍은 유용하다. `npcTrust: 70`, `questStage: 3`, `hasSeenIntro: true`처럼 플레이어의 선택과 세계 상태를 저장하면 분기와 반응을 관리하기 쉬워진다.

## 주의할 점

키 이름은 명확하고 중복되지 않아야 한다. 같은 의미를 `hp`, `health`, `HealthPoint`처럼 여러 이름으로 쓰면 데이터가 어긋나고 오류를 찾기 어려워진다.

또한 값의 자료형을 일관되게 관리해야 한다. 어떤 곳에서는 숫자로, 다른 곳에서는 문자열로 저장하면 비교와 계산에서 문제가 생긴다. 데이터베이스나 대규모 설정 파일에서는 [[데이터베이스 스키마 (Database Schema)]]처럼 구조를 명시하는 방식이 필요하다.

## 연결 개념

- [[딕셔너리 (Dictionary, CSharp 자료구조)]] | 키-값 쌍을 저장하고 조회하는 대표적인 자료구조다.
- [[ID (고윳값)]] | 키로 쓰기 좋은 고유 식별자다.
- [[데이터베이스 스키마 (Database Schema)]] | 키와 값의 구조, 관계, 자료형을 명확히 정의한다.
- [[데이터 테이블 (DataTable)]] | 여러 키-값 속성을 행과 열로 정리한 기획 데이터 형태다.
