# 절차적 콘텐츠 생성 (PCG)

## 핵심 정의

절차적 콘텐츠 생성은 디자이너가 모든 결과물을 직접 배치하는 대신, 규칙, 제약, 파라미터, 검증 조건을 설계해 시스템이 다양한 콘텐츠를 생성하게 만드는 방식이다. 던전, 맵, 아이템, 퀘스트, 음악, 지형, 적 배치처럼 반복 생산이 필요한 콘텐츠에 자주 쓰인다.

PCG의 핵심은 무작위성이 아니라, 의도된 결과가 나오도록 만드는 규칙이다. 단순히 랜덤하게 뽑는 것은 생성일 수 있지만, 플레이 가능한 구조와 의도된 경험을 안정적으로 만들지 못하면 좋은 PCG가 아니다.

## 작동 방식

PCG는 보통 목표 설정, 생성 규칙, 입력 파라미터, 생성 알고리즘, 검증 규칙의 흐름으로 작동한다. 예를 들어 던전 생성에서는 방의 수, 연결 방식, 필수 경로, 보상 위치, 적 배치, 막다른 길 비율 같은 조건을 함께 설계한다.

[[L-시스템 (L-Systems)]], 마르코프 체인, 노이즈 함수, 모듈 조합, 그래프 기반 생성 같은 방법은 모두 PCG의 도구가 될 수 있다. 중요한 것은 알고리즘 자체보다 그 알고리즘을 게임 목표에 맞게 제약하는 방식이다.

## 설계에서의 의미

PCG는 콘텐츠 양을 늘리는 도구이면서 동시에 시스템적 변주를 만드는 도구다. 플레이어마다 다른 상황을 제공하고, 반복 플레이의 신선함을 높이며, 디자이너가 직접 배치하기 어려운 조합 공간을 탐색하게 해준다.

그러나 PCG가 디자이너의 일을 없애지는 않는다. 직접 콘텐츠를 만드는 일에서 생성 규칙과 검증 기준을 설계하는 일로 작업의 성격이 바뀐다.

## 주의할 점

PCG는 테스트 범위를 크게 늘린다. 생성 가능한 조합이 많아질수록 막힌 경로, 불공정한 배치, 의미 없는 반복, 테마 붕괴가 생길 가능성이 커진다.

또한 무작위 결과가 많다고 플레이어가 다양성을 느끼는 것은 아니다. 플레이어가 실제로 체감하는 차이가 목표, 위험, 선택, 보상에 영향을 줄 때 다양성이 의미를 갖는다.
