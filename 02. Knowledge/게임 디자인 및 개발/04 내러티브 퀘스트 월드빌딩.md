# 내러티브 퀘스트 월드빌딩

## 핵심 관점

게임 내러티브는 텍스트나 컷신만으로 만들어지지 않는다. 플레이어가 수행하는 행동, 목표, 실패, 보상, 공간 이동, 선택의 결과가 모두 이야기의 일부가 된다. 따라서 게임 스토리텔링의 핵심은 `말해지는 이야기`와 `플레이되는 이야기`를 정렬하는 것이다.

## 내러티브 구조

전통적인 3막 구조, 갈등, 캐릭터 아크, 원형, 사건의 발단 같은 개념은 게임에서도 유효하다. 다만 게임에서는 플레이어가 속도와 순서를 바꿀 수 있기 때문에, 고정된 플롯보다 상황을 만들어내는 내러티브 시스템이 중요해진다.

## 퀘스트의 역할

퀘스트는 목표와 보상 목록이 아니라, 세계관, 플레이어 동기, 공간 탐색, 시스템 학습을 연결하는 장치다.

```text
세계의 문제
-> 플레이어 목표
-> 수행 행동
-> 장애물과 선택
-> 보상과 변화
-> 세계관 이해의 심화
```

## 월드빌딩

좋은 세계관은 모든 설정을 설명하지 않는다. 플레이어가 행동과 환경을 통해 세계의 규칙을 추론하게 만든다. 장소, 물건, NPC, 퀘스트, 적 배치, UI 용어까지 모두 세계관을 말하는 언어가 된다.

## 루도내러티브 조화

시스템이 요구하는 행동과 이야기가 말하는 가치가 충돌하면 플레이어는 부조화를 느낀다. 예를 들어 이야기는 희생과 윤리를 강조하는데 시스템은 무차별 수집과 학살만 보상한다면 메시지는 약해진다.
