# 가상 경제 보상 밸런싱

## 핵심 관점

게임 경제는 플레이어에게 아이템을 나눠주는 장치가 아니다. 시간, 노력, 희소성, 교환, 보상, 사회적 지위를 조직하는 제도다. 가상 경제는 플레이어 행동을 장기적으로 형성한다.

## 경제 시스템의 흐름

```text
재화 생성
-> 획득 활동
-> 소비처
-> 축적 또는 거래
-> 인플레이션/희소성 변화
-> 플레이 동기 변화
```

## 수도꼭지와 배수구

재화가 생성되는 지점은 수도꼭지, 재화가 사라지는 지점은 배수구다. 수도꼭지가 강하고 배수구가 약하면 인플레이션이 생긴다. 배수구가 지나치게 강하면 플레이어는 박탈감을 느낀다.

## 보상 정렬

보상은 플레이어가 하기를 원하는 행동과 정렬되어야 한다. 탐험 게임에서 최적 보상이 반복 사냥에만 있으면 플레이어는 탐험하지 않는다. 스토리 게임에서 보상이 숫자 성장에만 있으면 이야기의 긴장이 약해진다.

## 2차 시장과 운영 정책

가상 재화가 현실 화폐와 연결되면 경제 시스템은 게임 바깥의 시장과도 이어진다. 거래 허용 여부, 희소성 정책, 아이템 귀속, 경매장, 과금 모델은 모두 설계와 운영의 문제다.
