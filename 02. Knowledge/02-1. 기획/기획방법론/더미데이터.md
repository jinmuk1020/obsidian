
실제 [[데이터]]를 대신하여 시스템의 기능을 테스트하거나, 통계적 분석 모델을 구축하기 위해 임시로 사용하는 가상의 데이터를 의미. 사용되는 맥락에 따라 개발용 임시 리소스와 통계학적 가변수라는 두 가지 주요 의미를 가짐

게임 및 소프트웨어 개발에서의 더미데이터
개발 현장에서 더미 데이터는 실제 리소스가 준비되기 전, 시스템이 제대로 작동하는지 확인하기 위해 사용하는 임시 자료
정의 및 역할:실제 그래픽 리소스나 최종 수치가 확정되기 전,시스템 구현과 테스트를 위해 임시로 사용하는 최소한의 데이터.
중요성:더미 데이터를 활용하면 아트나 기획의 최종 결과물이 나올 때까지 기다리지 않고도 프로그래밍 로직을 선행해서 검증할 수 있어 개발 효율이 높아짐.

[[통계학]] 및 데이터 과학에서의 더미데이터
[[회귀분석 (Regression Analysis)|회귀 분석]]등 통계 모델링에서는 범주형 데이터를 수치로 변환한 이진 진표를 더미라고 부름
더미 변수화:성별이나 요일처럼 숫자가 아닌 범주형 변수를 0과 1의 이진값으로 변환하여 회귀 알고리즘에서 사용할 수 있도록 만드는 과정
자유도와 다중공선성
범주가 n개일 때 더미 변수는 n-1개를 사용해야 함
예를 들어,7일의 요일을 지정할 때 6개의 더미 변수만 사용. 만약 월요일부터 토요일까지 모두 0이라면 그날은 자동으로 일요일임을 알 수 있기 때문.
만약 7개 요일을 모두 더미 변수로 포함하면 다중공선성 오류가 발생하여 분석 모델이 실패하게 됨.

학습 및 [[시뮬레이션]]용 인공 데이터
알고리즘을 설명하거나 기계학습 모델을 연습할 때 사용하는 인공 데이터도 넓은 의미의 더미 데이터에 해당
목적:실제 [[데이터베이스]]에 없는 가상의 나이나 몸무게 등의 수치를 생성하여,모델이 예측값을 어떻게 도출하는지 학습하는 용도로 사용
장점:데이터의 특성을 임의로 조정할 수 있어 특정 알고리즘의 동작 원리를 명확하게 파악하는 데 유용

주의사항:[[GIGO]]
더미 데이터는 테스트와 설계 단계에서는 필수적이지만, 최종 결과물에는 반드시 실제 데이터가 사용되어야 함.
데이터의 순도:무가치한 데이터가 들어가면 무가치한 결과가 나온다는 원칙에 따라,실제 서비스나 분석 단계에서는 처음부터 제대로 된 고순도의 데이터를 사용하는 것이 중요함.
