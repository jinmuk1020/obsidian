# 관찰 자료

## 핵심 정의
관찰 자료는 사용자의 말이 아니라 행동, 환경, 맥락, 사용 순서, 반복되는 문제를 직접 보며 얻은 자료다. 인터뷰나 설문이 인식과 진술을 다룬다면, 관찰은 실제 행동과 상황의 흔적을 다룬다.

## 작동 방식
관찰은 현장, 사용 로그, 플레이테스트, 고객 여정, 업무 수행 장면에서 이루어진다. 관찰자는 무엇이 일어났는지, 어떤 조건에서 행동이 반복되는지, 사용자가 어디서 멈추거나 우회하는지 기록한다. 이후 패턴을 묶어 문제, 니즈, 제약, 설계 기회로 해석한다.

## 실무적 의미
관찰 자료는 사용자가 스스로 설명하지 못하는 문제를 발견하게 해준다. 기획 단계에서는 실제 사용 맥락을 확인해 잘못된 가설을 줄이고, 설계 단계에서는 개선 우선순위를 정하는 근거가 된다.

## 주의할 점
관찰은 해석이 개입되기 쉽다. 본 것과 추론한 것을 분리해 기록해야 한다. 관찰 대상이 조사받고 있다는 사실 때문에 행동을 바꾸는 효과도 조심해야 한다.
