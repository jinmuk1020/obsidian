# 브레인스토밍

## 한 문장 정의
브레인스토밍은/는 PDF 원문에서 다음 정의 근거로 확인된다: 아이디어는 여러 사람의 생각을 합치면 더 좋다는 것에서 출발 - 브레인스토밍은 머리 속이 정리되지 않은 혼란한 상태 : 아이디어를 낼 때 팀원들의 머리 상태 - 자유분방한 분위기에서 제멋대로 무책임적으로 많은 아이디어를 뽑아 낸다는 사고 방식임 - 탈 논리적 사고에서 새로운 아이디어가 나온다는 의미 브레인 스토밍 (Brainstorming)
