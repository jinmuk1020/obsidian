# 시간복잡도

## 핵심 정의
시간복잡도는 알고리즘의 실행 시간이 입력 크기에 따라 얼마나 빠르게 증가하는지 표현하는 척도다. 절대 시간을 재는 것이 아니라, 입력이 커질 때 연산량이 어떤 비율로 늘어나는지 본다.

## 작동 방식
보통 Big-O 표기로 나타낸다. O(1)은 상수 시간, O(log n)은 로그 시간, O(n)은 선형 시간, O(n²)은 입력 크기의 제곱에 비례하는 시간을 뜻한다. 반복문, 중첩 반복, 탐색 구조, 정렬 방식이 시간복잡도를 결정한다.

## 실무적 의미
기획자가 시간복잡도를 이해하면 기능 요구가 성능에 미치는 영향을 더 잘 판단할 수 있다. 검색, 추천, 매칭, 랭킹, 대량 로그 처리처럼 데이터가 커지는 기능에서는 UX와 서버 비용에 직접 영향을 준다.

## 주의할 점
Big-O는 큰 그림을 보여주지만 모든 성능을 설명하지는 않는다. 상수항, 캐시, I/O, 네트워크, 구현 언어, 데이터 분포도 실제 속도에 영향을 준다.
