# 프로젝트 관리자 (Project Manager)

프로젝트 관리자는 한정된 자원 안에서 프로젝트의 목표, 일정, 비용, 품질, 커뮤니케이션을 조율해 완료까지 이끄는 책임자다.

## 작동 방식

프로젝트 관리자는 프로젝트 범위, 일정, 비용, 인력, 품질, 커뮤니케이션을 함께 본다. 교차 기능 팀을 운영하며, 각 분야 전문가가 같은 목표를 향해 움직이도록 산출물과 의사결정 지점을 관리한다.

모든 세부 작업을 직접 통제하기보다는 게이트, 주요 산출물, 리스크, 이해관계자 기대를 관리하는 것이 핵심이다.

## 설계상 의미

프로젝트 관리자는 아이디어와 실행 사이의 간격을 줄인다. 특히 게임이나 신제품 개발처럼 여러 직군이 얽힌 작업에서는 누가 무엇을 언제까지 결정해야 하는지 명확히 해야 한다.

## 주의점

관리자가 세부 실행을 과도하게 통제하면 팀의 전문성과 속도가 떨어진다. 반대로 조율이 약하면 일정, 품질, 의사소통이 각자 흩어진다.
