## 핵심 설명

알고리즘은 유한한 단계 내에서 문제를 확실하게 해결하는 명백한 규칙과 절차의 집합을 의미합니다. 반면 휴리스틱은 항상 정답을 보장하지는 않지만, 탐색 작업을 효율적으로 진행하기 위해 경험에 근거하여 사용하는 '주먹구구식 규칙'입니다. 알고리즘이 수학적이고 정확한 답을 제시한다면, 휴리스틱은 불완전하더라도 합리적이고 빠른 답을 찾아주는 지름길 역할을 합니다.

## 핵심 포인트

- 확실한 해결 절차를 보장하는 알고리즘
- 경험적 정보로 탐색 시간을 단축하는 휴리스틱
- 문제의 성격에 따른 논리적 접근 방식의 차이

## 중요성

복잡한 문제 해결 상황에서 정밀한 분석이 필요한 경우와 빠른 판단이 필요한 경우를 구분하여 효율적으로 대응할 수 있습니다.

### 구체적 메커니즘

알고리즘은 유한한 길이의 조작과 명백한 규칙들의 집합을 통해 주어진 문제를 확실하게 해결하는 절차로 작동합니다 [1]. 특히 컴퓨터 알고리즘은 각 단계가 하나 이상의 연산으로 이루어진 정확한 방법을 사용하여 항상 정확한 답을 제시하는 기제를 가집니다 [1]. 이와 달리 휴리스틱은 탐색 작업을 대폭 축소하기 위해 항상 옳지는 않더라도 대부분의 경우에 잘 맞는 '경험에 의한 규칙(rules of thumb)'을 활용합니다 [1]. 이는 경험적 정보를 사용하여 탐색 작업을 효율적으로 진행하며, 최적해는 아니더라도 실무적으로 합리적인 답을 찾아주는 알고리즘의 일종으로 기능합니다 [1]. 결국 이러한 기법들은 현재의 상태와 목표 상태 간의 차이인 갭(Gap)을 인식하고 이를 해결하기 위한 대안을 적용하는 과정의 핵심 요소입니다 [1-3].

### 데이터와 구조

- 알고리즘의 속성: 유한한 길이의 조작, 명백한 규칙, 확실한 문제 해결 보장 [1]
- 휴리스틱의 도구: 경험적 정보 및 경험에 의한 규칙(rules of thumb) [1]
- 문제해결 기법의 4대 분류: 시행착오, 통찰, 알고리즘, 휴리스틱 [1, 3]
- 컴퓨터 알고리즘의 구조: 하나 또는 그 이상의 연산으로 구성된 정확한 방법 [1]
- 문제의 정의 기준: 현재 상태와 바람직한 목표 상태 사이의 차이(Gap) [2, 3]

### 사례와 적용

- 수학적 문제 풀이 사례: 명백한 규칙을 적용하여 유한한 단계 내에서 정답을 도출하는 알고리즘 적용 장면 [1]
- 효율적 탐색 사례: 탐색 작업을 축소하기 위해 경험적 정보를 활용하여 합리적인 대안을 빠르게 찾아내는 휴리스틱 활용 장면 [1]
- 컴퓨터 연산 수행 사례: 컴퓨터가 정의된 알고리즘의 각 연산 단계를 거쳐 정확한 해결책을 출력하는 실제 적용 사례 [1]
