# 설비엔지니어링 시스템 (EES)

## 핵심 정의
설비엔지니어링 시스템은 제조 설비의 상태와 성능 데이터를 수집하고 분석해 가동률, 품질, 생산성을 높이는 운영 시스템이다. 설비 효율 관리, 작업 조건 관리, 공정 제어, 이상 감지가 핵심 기능이다.

## 작동 방식
EES는 설비에서 발생하는 이벤트, 알람, 작업 조건, 공정 데이터를 실시간으로 수집한다. 이를 통해 가동률, 고장 간격, 수리 시간, 이상 징후를 분석하고, 공정 조건을 조정해 불량과 정지를 줄인다.

## 실무적 의미
EES는 제조 현장의 디지털화와 스마트 공장 운영의 기반이 된다. 설비가 언제, 왜 멈추는지 알 수 있어야 예방보전과 품질 안정화가 가능하다.

## 주의할 점
설비 데이터를 많이 모으는 것만으로 성과가 나지 않는다. 데이터 정의, 설비 코드, 알람 기준, 현장 대응 절차가 정리되어야 한다. 현장 작업자의 입력 품질도 시스템 성과에 큰 영향을 준다.

## 연결된 생각
- [[가동률 (Utilization Rate)]]: EES는 설비 가동률을 측정하고 개선하는 데 쓰인다.
- [[비즈니스 프로세스 (Business Process)]]: 설비 운영도 입력, 활동, 출력으로 이루어진 프로세스다.
- [[디지털화 (Digitalization)]]: 설비 데이터를 디지털화하면 운영 개선의 근거가 생긴다.
