# 네트워크 효과 (Network Effects)

## 핵심 정의

네트워크 효과는 어떤 제품이나 서비스의 사용자가 늘어날수록 각 사용자가 느끼는 가치가 증가하는 현상이다. 사용자가 많아질수록 더 많은 연결, 더 많은 보완재, 더 높은 신뢰가 형성되면서 플랫폼의 매력이 커진다.

## 작동 방식

직접 네트워크 효과는 같은 사용자 집단 안에서 연결 가치가 커지는 경우다. 메신저나 SNS처럼 더 많은 사람이 사용할수록 개별 사용자의 효용이 직접 높아진다.

간접 네트워크 효과는 한쪽 사용자 집단이 늘어나면서 보완재나 다른 사용자 집단이 늘어나는 경우다. 운영체제 사용자가 많아지면 앱 개발자가 늘고, 앱이 많아지면 다시 사용자가 늘어나는 구조가 여기에 해당한다.

## 실무적 의미

네트워크 효과는 플랫폼 비즈니스의 성장과 방어력의 핵심 원천이다. 임계 규모를 넘으면 신규 사용자가 다시 신규 사용자를 끌어들이는 선순환이 생길 수 있다.

따라서 초기에는 품질만큼이나 참여자 확보가 중요하다. 어떤 쪽 사용자를 먼저 모을지, 보조금을 줄지, 개방과 통제 사이에서 어떤 전략을 선택할지가 플랫폼의 성패를 좌우한다.

## 주의할 점

사용자가 많다고 항상 네트워크 효과가 강한 것은 아니다. 참여자 간 연결이 실제 가치를 만들지 못하거나, 품질 저하와 혼잡이 커지면 네트워크가 오히려 부담이 될 수 있다.

또한 네트워크 효과는 승자독식으로 이어질 수 있지만, 차별화된 세그먼트나 멀티호밍이 쉬운 시장에서는 지배력이 약해질 수 있다.
