# 기술적 모순 (Technical Contradiction)

## 핵심 정의

기술적 모순은 어떤 특성을 개선하면 다른 특성이 악화되는 문제 상황이다. 더 빠르게 만들면 안정성이 떨어지거나, 더 가볍게 만들면 강도가 약해지는 식의 트레이드오프가 대표적이다.

## 작동 방식

기술적 모순은 두 성능 변수 사이의 충돌로 표현된다. 문제 해결자는 “개선하려는 특성”과 “악화되는 특성”을 분리해 정의한 뒤, 기존 타협이 아니라 모순을 우회하거나 제거하는 해결 원리를 찾는다.

TRIZ에서는 기술적 모순을 40가지 발명원리와 연결해 해결 아이디어를 탐색한다. 중요한 것은 문제를 막연한 어려움으로 보지 않고, 어떤 속성과 어떤 속성이 충돌하는지 선명하게 만드는 것이다.

## 실무적 의미

기술적 모순을 정의하면 문제 해결의 초점이 분명해진다. 단순히 비용을 낮추거나 품질을 높이라는 요구보다, 어떤 성능 개선이 어떤 부작용을 만드는지 표현해야 혁신적 대안을 찾기 쉽다.

비즈니스에서도 비슷한 구조가 나타난다. 고객 서비스를 강화하면 인건비가 늘고, 제품 다양성을 늘리면 운영 복잡성이 커지는 식이다. 이때도 모순을 명확히 정의하면 타협이 아닌 설계 전환을 모색할 수 있다.

## 주의할 점

모든 트레이드오프가 기술적 모순은 아니다. 실제로는 요구사항이 잘못 정의되었거나, 측정 기준이 부정확하거나, 시스템 경계가 좁아서 모순처럼 보이는 경우도 있다. 먼저 문제 경계와 성능 변수를 정확히 잡아야 한다.
