# DMAIC

## 핵심 정의
DMAIC는 Define, Measure, Analyze, Improve, Control의 다섯 단계로 기존 프로세스의 문제를 데이터 기반으로 개선하는 절차다. [[6시그마 (6 Sigma)]]에서 가장 널리 쓰이는 개선 로드맵이다.

DMAIC의 핵심은 문제 해결을 즉흥적인 개선안에서 시작하지 않고, 문제 정의와 측정, 원인 분석을 거쳐 개선과 관리로 이어지게 만드는 데 있다.

## 작동 방식
Define 단계에서는 고객 요구와 문제 범위를 정의한다. Measure 단계에서는 현재 프로세스의 성과를 지표로 측정한다. Analyze 단계에서는 결함이나 변동을 만드는 근본 원인을 찾는다.

Improve 단계에서는 원인에 대응하는 개선안을 설계하고 실험한다. Control 단계에서는 개선 결과가 시간이 지나도 유지되도록 표준, 지표, 관리 체계를 만든다.

## 실무적 의미
DMAIC는 품질 개선, 비용 절감, 리드타임 단축, 오류 감소처럼 반복되는 프로세스 문제를 다룰 때 유용하다. 각 단계가 산출물과 판단 기준을 갖기 때문에 개선 활동이 개인의 경험에만 의존하지 않게 해준다.

컨설팅 프로젝트에서는 문제 증상과 원인을 분리하고, 개선 효과를 측정 가능한 형태로 제시하는 데 도움이 된다.

## 주의할 점
Analyze 단계가 약하면 DMAIC는 표면적인 개선에 그친다. 원인을 충분히 검증하지 않고 Improve로 넘어가면 임시방편이 반복된다.

Control 단계도 중요하다. 관리 체계가 없으면 개선 효과는 시간이 지나며 사라지고, 조직은 같은 문제를 다시 해결해야 한다.
