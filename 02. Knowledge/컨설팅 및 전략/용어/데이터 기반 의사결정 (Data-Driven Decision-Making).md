# 데이터 기반 의사결정 (Data-Driven Decision-Making)

## 핵심 정의

데이터 기반 의사결정은 직관이나 관행만이 아니라 관찰 가능한 데이터와 분석 결과를 근거로 선택하는 방식이다. 목적은 의사결정의 정확성, 설명 가능성, 학습 가능성을 높이는 것이다.

## 작동 방식

데이터 기반 의사결정은 문제 정의, 데이터 수집, 분석, 대안 비교, 실행, 결과 측정으로 이어진다. 데이터는 과거를 설명하는 데 그치지 않고, 선택지의 결과를 예측하고 가정을 검증하는 근거가 된다.

좋은 의사결정은 데이터가 말하는 것과 데이터가 말하지 못하는 것을 함께 구분한다. 데이터는 판단을 대체하는 것이 아니라 판단의 질을 높이는 재료다.

## 실무적 의미

기업은 수요 예측, 고객 세분화, 재고 관리, 추천 시스템, 가격 정책, 인사 의사결정에서 데이터를 활용한다. 데이터가 축적될수록 반복 의사결정은 더 빠르고 일관되게 처리할 수 있다.

또한 데이터 기반 의사결정은 조직 내 토론을 개인 의견의 충돌에서 가정과 근거의 검증으로 이동시킨다.

## 주의할 점

데이터가 많다고 좋은 의사결정이 되는 것은 아니다. 데이터 품질, 측정 편향, 잘못된 인과 해석, 모델의 목적 불일치가 있으면 오히려 잘못된 확신을 만들 수 있다. 정량 분석과 현장 맥락을 함께 봐야 한다.
