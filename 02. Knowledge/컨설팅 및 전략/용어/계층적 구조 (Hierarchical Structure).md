# 계층적 구조 (Hierarchical Structure)

## 핵심 정의

계층적 구조는 목표, 문제, 의사결정, 조직 단위를 상위 수준에서 하위 수준으로 나누어 정렬하는 구조화 방식이다. 복잡한 대상을 한 번에 다루지 않고 단계별 수준으로 분해해 전체와 부분의 관계를 명확히 만든다.

## 작동 방식

전략에서는 기업 차원의 목표가 사업부 전략, 기능 전략, 실행 과제로 내려간다. 문제 해결에서는 큰 질문을 하위 질문으로 분해하고, 하위 질문의 답이 모여 상위 결론을 지지하도록 구성한다.

계층은 단순한 목록이 아니라 포함 관계와 책임 관계를 가진다. 상위 항목은 방향과 판단 기준을 제공하고, 하위 항목은 실행 단위와 분석 단위를 제공한다.

## 실무적 의미

계층적 구조는 전략 전개, 조직 설계, 업무 분장, 보고서 구성에 특히 유용하다. 상위 목표와 하위 활동이 연결되면 어떤 활동이 왜 필요한지 설명하기 쉬워지고, 중복 업무나 빠진 과제를 찾기도 쉬워진다.

컨설팅 작업에서는 문제를 계층화해야 인터뷰 질문, 데이터 수집, 분석 결과, 제안 메시지가 서로 어긋나지 않는다. 좋은 계층 구조는 분석의 순서를 정하는 동시에 커뮤니케이션의 뼈대가 된다.

## 주의할 점

계층을 너무 경직되게 만들면 현장의 예외, 순환 관계, 피드백을 놓칠 수 있다. 따라서 계층화는 복잡성을 정리하기 위한 도구이지, 현실을 무리하게 단순화하기 위한 틀이 되어서는 안 된다.
