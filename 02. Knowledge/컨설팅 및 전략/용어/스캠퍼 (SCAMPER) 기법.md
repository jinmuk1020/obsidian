# 스캠퍼 (SCAMPER) 기법

## 핵심 정의
스캠퍼는 기존 제품, 서비스, 아이디어를 변형해 새로운 아이디어를 찾는 발상 기법이다. Substitute, Combine, Adapt, Modify, Put to another use, Eliminate, Reverse의 앞글자를 딴 체크리스트다.

## 작동 방식
각 질문은 기존 대상을 다른 방식으로 보게 만든다. 무엇을 대체할 수 있는가, 무엇과 결합할 수 있는가, 다른 맥락에 적용할 수 있는가, 무엇을 수정하거나 제거할 수 있는가를 차례로 묻는다.

## 실무적 의미
스캠퍼는 막연한 창의성에 의존하지 않고 제품 개선과 서비스 혁신 아이디어를 체계적으로 만들게 해 준다. 워크숍, 신제품 기획, 문제 해결 회의에서 빠르게 활용하기 좋다.

## 주의할 점
스캠퍼는 아이디어를 많이 내는 도구이지 좋은 아이디어를 자동으로 골라 주는 도구가 아니다. 도출된 아이디어는 고객 가치, 실행 가능성, 비용, 전략 적합성으로 다시 평가해야 한다.
