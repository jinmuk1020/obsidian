# 로직 트리 (Logic Tree)

## 핵심 정의

로직 트리는 복잡한 문제를 하위 요소로 분해해 원인, 대안, 실행 과제를 구조적으로 찾는 도구다. 문제를 한 번에 해결하려 하지 않고, 질문을 가지처럼 나누어 어디를 분석해야 하는지 명확히 만든다.

## 작동 방식

상위 질문을 두고 이를 구성하는 하위 질문으로 쪼갠다. 예를 들어 매출 감소 문제는 가격, 판매량, 제품 믹스, 고객 세그먼트로 나눌 수 있고, 판매량은 다시 신규 고객, 재구매, 이탈로 나눌 수 있다.

좋은 로직 트리는 빠짐과 중복이 적고, 각 가지가 데이터로 확인 가능한 질문으로 내려간다.

## 실무적 의미

로직 트리는 분석 범위를 정하고 팀의 문제 인식을 맞추는 데 유용하다. 무엇을 볼지 명확해야 데이터 수집이 낭비되지 않고, 고객에게 문제 해결 경로를 투명하게 설명할 수 있다.

## 주의할 점

처음 만든 트리가 곧 정답은 아니다. 분석이 진행되면서 가지를 합치거나 나누어야 한다. 모든 가지를 같은 깊이로 분석하기보다 영향도와 불확실성이 큰 가지에 집중해야 한다.
