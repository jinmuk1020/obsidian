# So What So How

## 핵심 정의
So What은 분석 결과가 왜 중요한지 묻는 질문이고, So How는 그 중요성을 바탕으로 무엇을 실행할지 묻는 질문이다. 두 질문은 데이터와 관찰을 의사결정 가능한 메시지와 실행안으로 바꾸는 컨설팅 사고 도구다.

## 작동 방식
분석 결과는 그 자체로 의사결정이 아니다. 예를 들어 "매출이 감소했다"는 사실에서 멈추면 보고는 정보 저장소가 된다. So What은 그 감소가 어떤 전략적 위험이나 기회를 뜻하는지 해석하게 만든다.

So How는 해석을 실행 방안으로 내린다. 가격 조정, 채널 개선, 고객 세분화, 비용 구조 개선, 조직 개편처럼 실제 행동으로 이어질 때 분석은 의사결정에 기여한다.

## 진단 질문
- 이 분석 결과가 의사결정자에게 왜 중요한가.
- 이 결과는 기존 가정을 지지하는가, 뒤집는가.
- 그래서 무엇을 바꾸어야 하는가.
- 실행하려면 누가, 언제, 어떤 순서로 움직여야 하는가.

## 실무적 의미
So What과 So How는 보고서를 실행 가능한 권고안으로 바꾼다. 좋은 분석은 흥미로운 사실을 넘어, 의사결정자가 어떤 선택을 해야 하는지까지 이어져야 한다.

컨설팅 문서에서는 보통 사실, 해석, 시사점, 실행안이 이어진다. So What은 해석과 시사점을 만들고, So How는 실행안으로 연결한다.

## 주의할 점
So What 없이 So How로 바로 가면 근거 없는 처방이 된다. 반대로 So What만 있고 So How가 없으면 통찰은 있지만 실행이 없다. 두 질문은 순서대로 연결되어야 한다.
