# 적정 기술 (Appropriate Technology)

## 핵심 정의
> 적정 기술은 특정 지역과 사용자의 사회적, 경제적, 환경적 조건에 맞게 설계되어 실제로 유지되고 사용할 수 있는 기술이다.

* **본질:** 가장 최신이거나 가장 고성능인 기술이 아니라, 맥락에 가장 적합한 기술이다.
* **기준:** 비용, 수리 가능성, 학습 난이도, 현지 재료, 에너지 조건, 운영 주체
* **목표:** 사용자의 자율성과 삶의 질을 지속적으로 높이는 것

## 작동 방식
적정 기술은 먼저 사용 환경을 읽는다. 전기 공급이 안정적인지, 부품을 구할 수 있는지, 사용자가 직접 수리할 수 있는지, 현지에서 생산하거나 운영할 수 있는지 확인한다. 그 결과 복잡한 첨단 장치보다 단순하고 견고한 구조가 더 적합한 경우가 많다.

디자인 관점에서 적정 기술은 “무엇을 만들 수 있는가”보다 “누가 어떤 조건에서 오래 사용할 수 있는가”를 묻는다. 기술적 완성도는 성능만이 아니라 접근성, 유지 가능성, 지역 적합성으로 평가된다.

## 실무적 의미
적정 기술은 사회적 디자인, 공공디자인, 개발협력, 재난 대응, 지속 가능 제품 디자인에서 중요하다. 좋은 의도로 만든 해결책도 현지의 기술 역량과 생활 조건을 반영하지 않으면 유지되기 어렵다.

적정 기술은 유니버설 디자인과도 만난다. 두 접근 모두 추상적인 평균 사용자가 아니라 실제 조건 속의 다양한 사람을 기준으로 삼는다.

## 주의할 점
적정 기술은 낮은 수준의 기술을 뜻하지 않는다. 핵심은 기술 수준을 낮추는 것이 아니라 맥락에 맞게 조정하는 것이다. 또한 외부 전문가가 일방적으로 만든 해결책은 현지 지식과 참여를 반영하지 못해 실패하기 쉽다.
