# 실행과 평가의 간극 (Gulfs of Execution and Evaluation)

## 핵심 정의
> 실행과 평가의 간극은 사용자가 시스템을 조작하려 할 때 겪는 두 가지 어려움, 즉 “어떻게 해야 하는가”와 “무슨 일이 일어났는가”를 이해하기 어려운 상태를 말한다.

* **실행의 간극:** 사용자가 목표를 행동으로 옮기기 어려운 상태
* **평가의 간극:** 사용자가 시스템의 상태와 결과를 해석하기 어려운 상태
* **핵심 목표:** 좋은 디자인은 두 간극을 줄여 사용자가 자연스럽게 행동하고 결과를 이해하게 만든다.

## 작동 방식
실행의 간극은 사용자가 무엇을 해야 할지 알 수 없을 때 생긴다. 버튼이 눌리는지, 어느 방향으로 돌려야 하는지, 어떤 메뉴에 기능이 있는지 모르면 사용자는 추측과 시행착오에 의존한다. 어포던스, 기표, 자연적 대응은 실행의 간극을 줄이는 대표 장치다.

평가의 간극은 사용자가 행동한 뒤 결과를 해석하지 못할 때 생긴다. 저장이 되었는지, 오류가 났는지, 다음 단계로 넘어갔는지 알 수 없으면 사용자는 불안해진다. 피드백, 상태 표시, 명확한 메시지, 진행 표시가 평가의 간극을 줄인다.

## 실무적 의미
이 개념은 인터페이스, 제품, 공간 안내, 서비스 절차를 점검하는 강력한 기준이다. 사용자가 어디에서 멈추는지 볼 때, 그 문제가 조작 방법을 몰라서인지, 결과를 이해하지 못해서인지 구분할 수 있다.

예를 들어 문 손잡이가 밀어야 할지 당겨야 할지 알려주지 않으면 실행의 간극이 크다. 온라인 결제 후 확인 메시지가 없으면 평가의 간극이 크다. 두 간극을 줄이면 사용자는 시스템을 더 신뢰하고 적은 학습 비용으로 사용할 수 있다.

## 주의할 점
모든 간극을 완전히 없애야 하는 것은 아니다. 게임, 교육, 전문 도구에서는 의도적인 학습과 탐색이 필요할 수 있다. 그러나 사용자가 기본 조작과 결과 확인에서 불필요하게 혼란을 겪는다면 그것은 좋은 긴장이 아니라 나쁜 사용성이다.
