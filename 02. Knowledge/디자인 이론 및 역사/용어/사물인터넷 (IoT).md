# 사물인터넷 (IoT)

## 핵심 정의
> 사물인터넷은 물리적 사물이 센서, 네트워크, 소프트웨어를 통해 데이터를 수집하고 다른 기기나 서비스와 연결되는 기술 환경이다.

* **본질:** 사물이 단독 제품에서 연결된 서비스의 접점으로 바뀐다.
* **디자인 쟁점:** 형태뿐 아니라 데이터 흐름, 알림, 자동화, 유지 관리, 보안까지 설계해야 한다.
* **핵심 가치:** 사용자가 직접 조작하지 않아도 상황을 인식하고 필요한 행동을 돕는 것

## 작동 방식
IoT 제품은 보통 감지, 연결, 해석, 반응의 구조로 작동한다. 센서가 온도, 위치, 움직임, 사용 패턴 같은 데이터를 수집하고, 네트워크가 이를 다른 기기나 서버로 전달한다. 시스템은 데이터를 해석해 사용자에게 알림을 보내거나, 기기 상태를 자동으로 조정하거나, 다음 행동을 제안한다.

디자인 관점에서 IoT는 물건의 경계를 넓힌다. 사용자는 제품 하나만 경험하는 것이 아니라 앱, 알림, 클라우드 계정, 고객 지원, 업데이트, 데이터 기록까지 하나의 서비스로 경험한다. 따라서 연결된 제품은 물리적 사용성과 디지털 사용성이 함께 좋아야 한다.

## 실무적 의미
IoT 디자인에서는 “연결할 수 있는가”보다 “연결이 실제로 필요한가”가 더 중요하다. 연결 기능이 사용자의 문제를 줄이지 못하면 복잡성, 보안 위험, 유지 비용만 늘어난다. 좋은 IoT 디자인은 사용자가 기술을 의식하지 않아도 생활이 더 자연스럽게 조정되도록 만든다.

또한 IoT는 시간이 지나도 관리되어야 한다. 펌웨어 업데이트, 데이터 정책, 기기 수명, 서버 종료, 계정 이전, 오류 상황까지 고려하지 않으면 제품은 구매 이후에 빠르게 불편한 시스템이 될 수 있다.

## 주의할 점
IoT 제품은 개인정보와 보안 문제를 동반한다. 어떤 데이터를 수집하는지, 어디에 저장하는지, 사용자가 어떻게 통제할 수 있는지 명확해야 한다. 연결 실패나 센서 오작동이 실제 생활의 불편이나 안전 문제로 이어질 수 있다는 점도 고려해야 한다.
