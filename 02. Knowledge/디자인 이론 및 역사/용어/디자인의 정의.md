# 디자인의 정의

## 핵심 정의
> 디자인은 인간의 목적과 필요를 바탕으로 기능, 형태, 의미를 계획하고 표현하여 사용 가능한 결과로 만드는 창조적 문제 해결 행위다.

* **핵심 대상:** 제품, 시각 정보, 공간, 서비스, 시스템 등 사람이 경험하고 사용하는 모든 인공물
* **핵심 활동:** 문제 정의, 계획, 구성, 표현, 검증, 구현
* **핵심 가치:** 유용성, 심미성, 이해 가능성, 접근성, 사회적 적합성

## 작동 방식
디자인은 ‘예쁘게 만드는 일’보다 넓다. 어떤 목적을 가진 결과물을 만들기 위해 사용자의 필요, 기술적 조건, 재료, 비용, 문화적 의미, 사용 환경을 함께 고려한다. 따라서 디자인은 감각적 표현과 논리적 문제 해결이 결합된 활동이다.

디자인은 보이지 않는 요구를 보이는 구조로 바꾼다. 사용자가 겪는 불편, 조직이 전달하려는 메시지, 공간이 제공해야 할 경험은 처음에는 추상적이다. 디자이너는 이를 조사하고 해석한 뒤 형태, 색, 레이아웃, 동선, 인터랙션, 재료 같은 요소로 구체화한다.

* **문제 해결:** 사용자의 불편이나 조직의 목표를 디자인 과제로 바꾼다.
* **형태 구성:** 기능과 의미가 드러나도록 시각적·물리적 구조를 만든다.
* **경험 설계:** 사용자가 대상을 만나고 이해하고 사용하는 흐름을 조직한다.
* **가치 창출:** 기능적 효용과 미적 만족, 사회적 의미를 함께 만든다.

## 실무적 의미
디자인의 정의를 명확히 하면 프로젝트에서 디자인의 역할을 제대로 설정할 수 있다. 디자인을 단순 시각 마감으로 보면 문제 정의와 구조 설계가 이미 끝난 뒤에야 디자이너가 참여하게 된다. 반대로 디자인을 문제 해결 과정으로 보면, 초기 조사와 전략 수립 단계부터 디자인 판단이 필요해진다.

현대 디자인은 물건을 만드는 영역을 넘어 서비스, 경험, 조직, 정책, 데이터 기반 인터페이스까지 확장되어 있다. 그러나 중심에는 여전히 인간의 필요를 이해하고 그것을 더 나은 형태와 경험으로 바꾸는 일이 있다.

## 주의할 점
디자인을 너무 좁게 정의하면 장식이나 스타일링으로 오해하기 쉽고, 너무 넓게 정의하면 전문적 판단 기준이 흐려진다. 균형 잡힌 정의는 디자인을 목적 있는 계획과 감각적 구현, 그리고 실제 사용 경험의 결합으로 이해하는 것이다.

또한 좋은 디자인은 디자이너의 의도만으로 결정되지 않는다. 사용자가 실제로 이해하고 사용할 수 있어야 하며, 사회적·기술적·경제적 조건 속에서 지속 가능해야 한다.
