# 알고리즘 (Algorithm)

## 핵심 설명
알고리즘은 문제를 해결하기 위해 정해진 순서로 수행되는 명확한 절차다. 입력을 받아 처리하고, 그 결과를 출력하는 규칙의 묶음으로 볼 수 있다.

좋은 알고리즘은 모호하지 않고, 유한한 단계 안에서 실행 가능하며, 같은 조건에서는 일관된 결과를 만든다.

## 왜 중요한가
알고리즘은 계산 가능한 문제를 반복 가능하게 해결하는 방식이다. 검색, 정렬, 경로 탐색, 추천, 최적화, 시뮬레이션처럼 많은 시스템의 성능과 품질은 어떤 알고리즘을 쓰느냐에 따라 달라진다.

## 평가 기준
- 정확성: 원하는 문제를 제대로 해결하는가
- 시간 복잡도: 입력이 커질 때 실행 시간이 어떻게 증가하는가
- 공간 복잡도: 필요한 메모리가 얼마나 늘어나는가
- 안정성: 예외 상황에서도 예측 가능하게 작동하는가
- 구현 가능성: 실제 환경에서 유지보수할 수 있는가

## 주의할 점
알고리즘은 문제 정의와 데이터 구조에 의존한다. 같은 알고리즘도 입력 특성, 제약 조건, 실제 운영 환경에 따라 성능이 달라질 수 있다. 따라서 이론적 효율성과 실제 사용 맥락을 함께 봐야 한다.
