# 점수 모형 (Scoring Model)

## 핵심 설명
점수 모형은 여러 평가 기준에 점수와 가중치를 부여해 대안의 우선순위를 정하는 정량 평가 방법이다. 하나의 기준으로 판단하기 어려운 선택을 구조화하고, 왜 특정 대안을 선택했는지 설명 가능하게 만든다.

## 왜 중요한가
신규 사업, 기술 대안, 입지 후보, 프로젝트 포트폴리오처럼 여러 기준을 동시에 고려해야 하는 상황에서는 직감만으로 비교하기 어렵다. 점수 모형은 기준과 가중치를 명시해 판단 과정을 투명하게 만든다.

## 기본 절차
1. 평가할 대안을 정한다.
2. 평가 기준을 정한다.
3. 기준별 가중치를 부여한다.
4. 대안별 점수를 매긴다.
5. 점수와 가중치를 결합해 총점을 계산한다.
6. 결과가 가정에 얼마나 민감한지 확인한다.

## 주의할 점
점수 모형의 약점은 기준과 가중치가 설계자의 판단에 의존한다는 점이다. 숫자가 있다고 해서 객관성이 자동으로 보장되지는 않는다. 가중치의 근거와 점수 부여 기준을 함께 기록해야 한다.
