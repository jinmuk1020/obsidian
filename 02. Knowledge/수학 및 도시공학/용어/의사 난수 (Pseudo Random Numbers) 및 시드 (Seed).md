# 의사 난수 (Pseudo Random Numbers) 및 시드 (Seed)

## 핵심 설명
의사 난수는 완전한 무작위가 아니라 알고리즘이 만들어내는 난수처럼 보이는 수열이다. 같은 알고리즘에 같은 시드를 넣으면 같은 난수열이 반복해서 생성된다.

시드는 난수 생성기의 시작 상태를 정하는 값이다. 따라서 시드는 무작위성과 재현성을 동시에 다루는 핵심 장치다.

## 왜 중요한가
시뮬레이션, 게임, 통계 샘플링, 절차적 생성에서는 무작위성이 필요하지만, 결과를 다시 재현할 수 있어야 디버깅과 검증이 가능하다. 시드를 기록하면 같은 조건에서 같은 결과를 재생할 수 있다.

## 활용 예시
- 게임 맵이나 아이템의 절차적 생성
- 몬테카를로 시뮬레이션
- 실험 데이터 샘플링
- 테스트 케이스 자동 생성
- 암호학이 아닌 일반 난수 기반 선택

## 주의할 점
일반 의사 난수는 보안용 난수가 아니다. 예측 가능성이 문제가 되는 암호, 인증, 보안 토큰에는 암호학적으로 안전한 난수 생성기를 사용해야 한다.
