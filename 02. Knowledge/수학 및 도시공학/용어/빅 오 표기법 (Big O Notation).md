# 빅 오 표기법 (Big O Notation)

## 핵심 설명
빅 오 표기법은 입력 크기가 커질 때 알고리즘의 실행 시간이나 메모리 사용량이 얼마나 빠르게 증가하는지를 표현하는 방법이다. 정확한 실행 시간을 재는 것이 아니라, 입력 규모가 커질수록 지배적인 성장률이 무엇인지 본다.

예를 들어 `O(n)`은 입력이 두 배가 되면 대체로 작업량도 두 배가 되는 선형 성장을 뜻하고, `O(n^2)`은 입력이 두 배가 될 때 작업량이 약 네 배로 커지는 성장을 뜻한다.

## 왜 중요한가
작은 데이터에서는 비효율적인 알고리즘도 문제없이 작동할 수 있다. 그러나 입력이 커지면 성장률 차이가 성능을 결정한다. 빅 오 표기법은 특정 구현이나 하드웨어보다 알고리즘 구조 자체의 확장성을 비교하게 해준다.

## 대표 유형
- `O(1)`: 입력 크기와 무관하게 일정한 시간
- `O(log n)`: 입력이 커져도 완만하게 증가
- `O(n)`: 입력 크기에 비례해 증가
- `O(n log n)`: 효율적인 정렬 알고리즘에서 자주 나타남
- `O(n^2)`: 모든 쌍을 비교하는 구조에서 자주 나타남
- `O(2^n)`: 조합 폭발이 발생하는 구조

## 주의할 점
빅 오는 큰 입력에서의 성장률을 단순화한 표현이다. 상수항과 낮은 차수 항을 생략하기 때문에 작은 입력에서는 실제 성능과 다르게 보일 수 있다. 또한 시간 복잡도와 공간 복잡도를 구분해서 봐야 한다.
