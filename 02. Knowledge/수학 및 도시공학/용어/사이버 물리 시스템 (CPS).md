# 사이버 물리 시스템 (CPS)

## 핵심 설명
사이버 물리 시스템은 센서, 소프트웨어, 네트워크, 물리 장치가 결합되어 현실 세계의 상태를 감지하고 계산 결과를 다시 물리적 행동으로 되돌리는 시스템이다. 핵심은 디지털 계산과 물리적 과정이 피드백 루프로 연결된다는 점이다.

스마트 공장, 자율주행, 스마트 그리드, 도시 인프라 모니터링처럼 현실 세계의 변화에 실시간으로 반응해야 하는 영역에서 중요하다.

## 왜 중요한가
CPS는 물리적 시스템을 단순히 관찰하는 데 그치지 않고, 데이터를 바탕으로 제어와 최적화를 수행한다. 이 때문에 설비 고장 예측, 에너지 효율 개선, 안전 관리, 교통 흐름 제어처럼 복잡한 운영 문제를 더 정밀하게 다룰 수 있다.

## 구성 요소
- 센서: 물리 세계의 상태를 데이터로 변환한다.
- 네트워크: 센서, 제어기, 시스템을 연결한다.
- 계산 모델: 데이터를 분석하고 다음 행동을 결정한다.
- 액추에이터: 계산 결과를 물리적 조작으로 실행한다.
- 피드백 루프: 실행 결과를 다시 감지해 시스템을 갱신한다.

## 주의할 점
CPS는 데이터 품질, 지연 시간, 보안, 장애 대응에 민감하다. 디지털 모델이 현실을 충분히 반영하지 못하면 잘못된 제어가 오히려 물리적 위험을 만들 수 있다.
